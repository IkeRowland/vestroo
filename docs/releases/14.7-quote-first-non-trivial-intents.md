# Release note: 14.7 — Quote-first for non-trivial walk-in intents

**Intent:** Align the web booking checkout with Q13: complex walk-in intents are reviewed by ops before payment.

**Behaviour (when `QUOTE_FIRST_FOR_NON_TRIVIAL_INTENTS` is ON — default when unset):**

- `point_to_point` and `corporate_pattern` are unchanged (PayFast after insert where applicable today).
- `hourly_hire` and `experience_package` on `/book/payment` → booking is created with `status = submitted`, customer sees an on-page “preparing your quote” confirmation, **no** PayFast step.
- `trip_request` funnel → same flag sets `status = submitted` (was `pending` when the flag is OFF) for visibility on `/ops/bookings`.

**Rollback:** Set `QUOTE_FIRST_FOR_NON_TRIVIAL_INTENTS` to `false` (or `0` / `no` / `off`) to restore legacy `pending` + PayFast for hourly/experience checkout and `pending` for trip-request inserts.

**Ops (training):** New walk-in submissions appear as **Submitted** on **`/ops/bookings`**. Use **Send quote** (Story 14.6) to email the customer when the quote is ready.

**Migrations:** None for 14.7; `submitted` is already an allowed `bookings.status` value.
