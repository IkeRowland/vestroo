**Relationship to BE.6.1 / BE.6.3:** **BE.6.6** is an **optional**, **product-gated** **machine-readable HTTP contract** for **external** callers (**webhooks**, **callbacks**, **health**, **unguessable capability URLs**, etc.). The **[module matrix](../capstone-backend-module-matrix.md)** remains the **single** **24-row** domain ↔ capability table; **BE.6.6** status (**not applicable** / **deferred** / **partial** with link to OpenAPI) appears in **one** clear **non-domain** location (see **AC2**). **[`docs/capstone-nest-rest-to-vestroo-mapping.md`](../capstone-nest-rest-to-vestroo-mapping.md)** explains **why** first-party UI prefers **Server Actions**; **OpenAPI** (if pursued) describes **only** **`src/app/api/**/route.ts`** surfaces the team **explicitly** treats as **public or partner** HTTP — **not** Nest Swagger **module-by-module** exhaustiveness.

**Explicit out of scope:** **Documenting Server Actions** as **OpenAPI paths** (they are **not** the default **public/partner** HTTP contract). **OpenAPI** for **Supabase PostgREST**, **internal** admin-only APIs, or **reference Nest** Swagger **full** parity **per module**. **Delaying** or **blocking** **`supabase/migrations/`**, **RLS** reviews, **Story 6.2**-class work, or any **epic-forbidden** dependency chain — **OpenAPI** is **parallel** and **lower priority** than **RLS** / **migrations**. **Treating OpenAPI as substitute** for **RLS** or **server-only** secret review (**NFR.3.1**).

**Constraining NFRs:**

- **NFR.3.1:** OpenAPI MUST **not** be framed as a **substitute** for **RLS** or **server-only** secret review; any **go** spec or **no-go** deferral note MUST include a **prominent** **disclaimer**: the contract describes **HTTP shape** **only**; **authorization** is **RLS + server implementation** — **not** implied by paths or schemas alone.
- **NFR.4.1:** **Deliverable** is **YAML or JSON** OpenAPI **3.x** under **`docs/`** when **go**; optional **TypeScript** tooling or **CI** validation (**redocly**, **`@apidevtools/swagger-parser`**) is **Phase C** / **TBD** story — **do not** mandate CI inside **6.6** unless product explicitly wants it in scope.

## Story

- As **platform / engineering**
- I want a **product-gated**, **time-boxed** decision on **OpenAPI 3** for **external** **Route Handlers** only, with **matrix visibility** for **no-go** and **discoverable** spec + **epic/index** links **only** when **go**
