## Story

- As **ops staff**, I need **`/ops/login`** to present a **polished SaaS sign-in** — **centered card** on **`bg-ops-canvas`**, **brand mark**, **single-column** **`OpsLoginForm`**, **rust accent** primary CTA, and **clear** recovery / admin-help copy — so I can **sign in** with **confidence** and **password-manager** support (**WCAG AA**).

- As **the codebase**, we need **presentation-only** changes (**chrome**) — **no** change to **`requireOpsStaffPage`**, **session**, **RLS**, or **Supabase** auth configuration unless **Task 0** documents a **pre-existing** defect (**NFR.17.6**).

## Acceptance Criteria (ACs)

1. **Route + files:** Update **`src/app/(public-ops)/ops/login/page.tsx`** and **`src/features/ops/components/OpsLoginForm.tsx`** — **Task 0** confirms any small extracted presentational components; preserve **`nextPath`** from **`searchParams.next`** when it starts with **`/ops`**, else default **`/ops/board`** (**verified** current behaviour).

2. **Layout:** **Centered** max-width card on **`bg-ops-canvas`**; **brand mark** above the card (**Task 0** asset vs existing logo component); **single-column** form — **FE.17.11**.

3. **`OpsLoginForm`:** **Primary submit** uses **`bg-ops-accent`** (and token-consistent hover/focus); fields remain **stacked** with consistent spacing — **FE.17.11**.

4. **Copy (epic):** Visible strings match intent: **“Vestroo Operations”** (subtitle / secondary line per **Task 0** layout), **“Forgot password?”** link (href per **Reconciliation**), footer **“Need an account? Contact your administrator.”** — all from **`ops-login-copy.ts`** (**NFR.17.8**).

5. **No SSO:** **No** social / OAuth buttons — **FE.17.11** / **NFR.17.6** intent (**staff** password auth unchanged).

6. **WCAG AA:** Contrast, focus states, and error announcement (**`role="alert"`** or equivalent retained/improved) meet **NFR.17.5** on the login surface.

7. **Autofill:** Email and password **`Input`**s keep **`autoComplete="username"`** and **`autoComplete="current-password"`** (or **Task 0**-approved equivalents) — password manager friendly — **FE.17.11**.

8. **Theme (NFR.17.4):** **`data-ops-theme`** applied for **`/ops/login`** per **Reconciliation** — **light** minimum; **dark** if required — **no** ad-hoc hex branching beyond tokens.

9. **Card chrome:** Card uses **`rounded-ops-card`** + **`shadow-ops-*`** (per **17.1**) instead of generic **`border-border` / `bg-card`** — **Reconciliation**.

10. **Parity doc (NFR.17.1):** **`docs/ops-design-system-parity.md`** **§ 17.19** — URL/query contract (`next`), theme scoping, copy keys, forgot-password target, a11y notes.

12. **`npm run lint`** and **`npm run test`** green.

13. **Mobile / tablet QA:** **`docs/ops-console.md`** (**FE.5.7**) or **Task 0** substitute — **sign-in** viewport checks recorded in **Progress Notes**.

14. **Vocabulary (NFR.17.7):** No forbidden Wheelzie rental vocabulary in user-visible copy.

15. **Non-regression:** **No** intentional change to **`requireOpsStaffPage`**, session loading, **`signInWithPassword`** semantics, or **RLS** — **chrome only** (**FE.17.11**); **Supabase** auth config changes **only** if **Task 0** files a defect with evidence.
