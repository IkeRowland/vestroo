## Reconciliation (mandatory)



| Issue | Resolution |

|-------|------------|

| **URL query param names** | **`page`** (1-based), **`per`** ∈ **`{10, 20, 50}`** — invalid **`per`** coerced to **`20`**. Canonical URLs omit **`page=1`** and **`per=20`**. |

| **`useSearchParams` / `nuqs` / plain `<Link>`** | **`next/link`** + pure **`buildOpsPaginationHref`** for page controls; **`useRouter().push`** only for **`per`** **`<Select>`** (`OpsPagination` client island). |

| **Truncation rules** | Implemented per **`buildPaginationWindowItems`** — **`totalPages ≤ 7`** full run; else ellipsis runs; **`totalPages === 0`** hides pager chrome (copy line only). |

| **Changing `per` resets to page 1** | **`buildOpsPaginationHref(..., { page: 1, per })`** on **`per`** change. |

| **Radix `Select` vs native `<select>`** | **`src/components/ui/select.tsx`** native **`<select>`** — **no** new Radix **Select** package. |

| **En dash vs hyphen** | **`ops-pagination-copy.showingRange`** uses **U+2013** between range endpoints. |

| **Pilot route in 17.8** | **No** — primitive-only (defaults per reconciliation). |



## Story



- As **ops staff**, I need **consistent pagination** (page window, prev/next, per-page, total count) that **matches Wheelzie 1 / 9** and **persists in the URL**, so I can **share links**, **refresh**, and use **browser history** without losing list position.



- As **the codebase**, we need a single **`OpsPagination`** primitive plus **`ops-pagination-copy.ts`** so **17.10+** never reimplement truncation or query keys (**epic acceptance**).



## Acceptance Criteria (ACs)



1. **`OpsPagination`:** Implemented under **`src/features/ops/`** (e.g. **`components/OpsPagination.tsx`** + small helpers colocated or under **`lib/`**) as the **shared** primitive for paginated **`/ops/*`** lists — **props** include at minimum: **`currentPage`** (1-based), **`totalPages`**, **`totalCount`**, **`perPage`** (must be one of **10 / 20 / 50**), **`basePath` or `searchParams` merge contract`** per **Task 0** — document full prop table in **`docs/ops-design-system-parity.md`** **§ 17.8**.

2. **Page numbers (epic):** Render **first**, **current ± 2**, **last**, with **`…`** truncation **between** non-contiguous runs; when **`totalPages ≤ 7`**, show **all** pages **without** ellipsis (**Reconciliation**).

3. **Prev / Next (epic):** Icon or text controls with **`aria-label`** strings from **`src/features/ops/copy/ops-pagination-copy.ts`** (**NFR.17.8**); **Prev** disabled on page **1**, **Next** disabled on **last** page (**keyboard** still skips disabled controls per platform — document focus behaviour in parity).

4. **"Results per page" (epic):** Control with options **10 / 20 / 50**; value **URL-persistent** as **`?per=20`** (epic example); invalid **`per`** in URL coerced per **Reconciliation**.

5. **Total count text (epic):** Visible pattern **`Showing 11–20 of 213`** (range uses **en dash** per **Reconciliation** / **Task 0**); **all** strings from **`ops-pagination-copy.ts`** (**NFR.17.8**) including labels for **"Results per page"**, **Prev/Next** `aria-label`s, and the **range + total** template with **stable** interpolation keys.

6. **URL contract (epic):** **All** page changes (**page**, **`per`**) update the URL; **full page refresh** and browser **back/forward** restore the same **page** and **`per`** (**Vitest**/**RTL** and/or pure **URL builder** tests prove string contract).

7. **`per` change resets page (default):** When **`per`** changes, navigation **MUST** apply **`page=1`** (or omit **`page`** if **Task 0** defines canonical “first page” as absent param — but **must** be **one** documented rule) — **Reconciliation**.

8. **Server-first (NFR.17.3):** Prefer a **Server Component** wrapper that reads **`searchParams`** from the **Next.js 15** **page** / parent and renders structure; **`'use client'`** only on the **smallest** interactive island (**Select**, client-only pieces if any) — **Task 0** documents split vs full-client fallback.

9. **Theming (NFR.17.4):** Spacing, borders, text, hover/active states use **ops tokens / Tailwind ops utilities** only — **no** ad-hoc hex for ops chrome.

10. **Accessibility (NFR.17.5):** Logical **focus order** (Prev → page numbers → Next → per-page); active page control exposes **`aria-current="page"`**; icon-only buttons have **`aria-label`** from copy module; **keyboard** operable for all interactive parts.

11. **Copy module (NFR.17.8):** Add **`src/features/ops/copy/ops-pagination-copy.ts`** (or extend an existing ops copy module **only** if **Task 0** proves consolidation — still **single export surface** for pagination strings).

12. **Unit / component tests:** **Vitest** + **RTL** — truncation snapshots (or deterministic DOM assertions) for representative **`totalPages`** (e.g. **1**, **7**, **8**, **15**, middle **50**); **Prev/Next** disabled states; **`per`** change produces expected **href** or query (per chosen pattern).

13. **URL builder tests (optional but recommended):** If **`buildOpsPaginationQuery`/`mergeOpsPaginationSearchParams`** (or equivalent) is extracted as **pure** functions, **Vitest** covers merge, strip, and **page-1-on-per-change** rules without mounting.

14. **Documentation (NFR.17.1):** **`docs/ops-design-system-parity.md`** **§ 17.8** — props table, **URL param table**, **a11y** notes, **keyboard**, truncation diagram or bullet rules, **Select vs native** decision, **RSC/client** boundary.

15. **Scope:** **This story** delivers **primitive + tests + § 17.8**; **does not** require wiring into **every** list in one PR — **17.10** and later **adopt**; **pilot route** only per **Reconciliation**.

16. **Quality gate:** **`npm run lint`** and **`npm run test`** green after implementation.
