## Story

- As **ops staff**, I need **`/ops/roster`** as a **week-at-a-glance** schedule of **driver shifts** with a **driver profile** and **shift** context in a **detail rail**, so I can **plan coverage** without scanning nested lists — using **shuttle** vocabulary (**NFR.17.7**).

- As **ops staff**, I need a **month** calendar primitive (**`OpsCalendarMonth`**) with **chips** and **overflow** (“**n** more”) where product places it (**Task 0**), so I can **scan density** across a month in line with **FE.17.9** — **without** heavy third-party calendar libraries.

- As **the codebase**, we need **`OpsCalendarMonth`** documented and **wired** per reconciliation, **`/ops/roster`** migrated from **driver list + nested shift list** to **`OpsCalendarWeek`** + **`OpsSplitView`**, and **keyboard**/**a11y** parity with **17.14** — **no** authorization changes (**NFR.17.6**).

## Acceptance Criteria (ACs)

2. **`events` contract:** Reuse **17.14** public shape **`{ id, startsAt, endsAt, title, subtitle, tone, href? }[]`** for chips positioning / overflow counts; **Task 0** defines how **multi-day** shifts (if any) appear vs single-day chips.

3. **First consumer:** **Task 0** choice **(A)** / **(B)** / **(C)** implemented and named in **`docs/ops-design-system-parity.md`** **§ 17.15**.

4. **`/ops/roster` route:** Refactor **`src/app/(ops)/ops/roster/page.tsx`** — replace or **substantially augment** today’s **driver list + nested shifts** (**`profiles`** **`PROFILE_ROLE_OPS_DRIVER_DB`**, **`DRIVER_SHIFT_SCHEDULE_TABLE`**, **`DRIVER_SHIFT_SCHEDULE_SELECT_COLUMNS`**, **`gte('work_date', today)`**, **`limit(80)`**) with layout: **`OpsCalendarWeek`** mapping **shifts** → **`events`** + **`OpsSplitView`** + **`OpsDetailRail`** (**Reconciliation**).

5. **Right rail content:** **Driver profile** (name, status, phone — **RLS-safe** columns already loaded or **Task 0**-approved additions) + **shift form / detail** per **Reconciliation** (**MVP** vs placeholder — **no** new RLS).

6. **Interaction:** **Click** shift event → **`OpsDetailRail`** (or **`event.href`** when set — **Task 0**); **Esc** closes rail; **focus return** aligned with **17.9** / **17.14**.

7. **Deep linking:** URL reflects **week** and/or **month** (per shipped toggles) and **selection** (**`?id=`** and/or shift id — **Task 0**); refresh and shared links restore state; invalid id behaviour documented.

10. **Accessibility:** **Icon-only** controls have **`aria-label`**; month grid exposes appropriate **roles/labels** for day cells and overflow control (**Task 0** pattern).

11. **Theme (NFR.17.4):** **`data-ops-theme` light/dark** — token-only styling for chips and grid.

12. **`OpsPageHeader` / chrome:** Roster page uses **ops** page header + description pattern **consistent** with **`/ops/calendar`** / **`/ops/trips`** (**Task 0** copy module name); **`OpsDataFreshnessBar`** preserved or rationalized.
