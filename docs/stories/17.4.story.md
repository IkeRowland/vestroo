## Story

- As **ops staff**, I need **dashboard KPI tiles** to read as **scorecards** (clear label, dominant value, trend hint, period delta), so I can **scan health** without opening each route.

- As **the product**, we need a **reusable `OpsKpiCard`** and a **visually aligned** **`NewBookingsHomeCard`**, so **`/ops`** matches the **Wheelzie-inspired** reference while preserving **Needs attention** behaviour.

## Acceptance Criteria (ACs)

1. **`OpsKpiCard` location:** New shared component at **[`src/features/ops/components/OpsKpiCard.tsx`](../../src/features/ops/components/OpsKpiCard.tsx)** (export pattern consistent with adjacent ops components).
2. **Header row:** Small **lucide** icon, **label** (string from copy module or consumer), optional **`…`** trigger opening **Radix `DropdownMenu`** with at least **View details** (or equivalent — copy via **NFR.17.8**).
3. **Value row:** **`text-3xl font-semibold tabular-nums`**; optional **unit suffix** (e.g. **ZAR**, **trips**); **skeleton** (or agreed loading chrome) when **`loading`** / value absent per **Task 0**.
4. **Delta row:** **Up/down arrow** + **percentage** + **configurable period label** (default **from last week** or epic-agreed string in copy module). Colors: **`text-ops-success`** when movement is **good**, **`text-ops-danger`** when **bad**, **`text-ops-muted`** when **neutral** — driven by **`deltaPolarity`** (or equivalent) **and** direction vs zero baseline (**Task 0** defines edge cases: null delta, exactly 0%, first week with no prior).
5. **Right column:** Fixed visual band **56–72px** tall for **inline trend**; per **Reconciliation default B**, **`sparkline`** is an **optional `ReactNode`** — **skeleton / empty reserved layout** acceptable until **17.5** provides **`OpsSparkline`**; when **`sparkline` is passed**, it must **not** collapse card height (**CLS**).
6. **Card root semantics:** Render **`<Link href={drillHref}>`** when **`drillHref`** is provided (preserve **`OpsDashboardView`** link behaviour); otherwise **`<div>`** (or non-nav wrapper **without** misleading **href**).
7. **Theme / tokens (NFR.17.4):** Card uses **`rounded-ops-card`**, border/shadow tokens established in **17.1**, and works under **`data-ops-theme="light"`** and **`"dark"`** without JSX theme branching beyond token utilities.
8. **`loadOpsDashboardKpis` MVP wiring:** **[`OpsDashboardView.tsx`](../../src/features/ops/components/OpsDashboardView.tsx)** maps **`result.kpis`** (or current shape) through **`OpsKpiCard`** for every KPI tile **in scope for 17.4** per **Reconciliation Task 0** — **no requirement** to implement **`loadOpsRevenueWeek`**, **`loadOpsDriversOnDuty`**, or **`loadOpsAwaitingPayment`** inside **17.4** unless PO explicitly expands scope.
9. **`NewBookingsHomeCard`:** Component **kept**; **Needs attention** pill and **bespoke data logic unchanged**; **visual treatment** (padding, type scale, border, hover lift if used elsewhere) **aligned** to **`OpsKpiCard`** scorecard language (**Task 0** lists concrete class alignment).
10. **PR / review:** **Visual diff** vs Wheelzie refs **6** / **10** (or crops attached to PR) **reviewed** — documented in **Progress Notes** and/or **PR template** “Ops visual redesign” section.
11. **Copy (NFR.17.8):** New user-visible strings for **`OpsKpiCard`** (menu labels, default period label, aria labels) live in **`src/features/ops/copy/ops-dashboard-copy.ts`** **or** **`src/features/ops/copy/ops-kpi-card-copy.ts`** — **single export surface** per choice in **Task 0**.
12. **Authz (NFR.17.6):** **No** changes to **`requireOpsStaffPage`**, RLS policies, or role mapping; **17.4** is **presentation + existing loader wiring** only.
13. **Documentation:** Add **[`docs/ops-design-system-parity.md`](../ops-design-system-parity.md)** **§ 17.4** — props table, skeleton states, polarity rules, **`sparkline` slot**, **Link vs div**, keyboard/menu a11y (**NFR.17.1** / **NFR.17.5**).
14. **Tests:** Add **component tests** for **`OpsKpiCard`** covering **polarity classes**, **Link vs div**, **skeleton** path; **optional** snapshot if stable. **Do not remove** existing **`NewBookingsHomeCard`** integration coverage if present — **extend** or **update selectors** only as needed for styling.
15. **Quality:** **`npm run lint`** and **`npm run test`** remain green after implementation.
