# Story 19.15: Ops team management and staff profile

## Status: Done

## Story

- As a **platform admin**, I need a **Team** page to list, invite, activate/deactivate, and remove ops staff (`admin` / `dispatcher`) so I can manage console access.
- As **ops staff** (admin or dispatcher), I need **`/ops/profile`** to edit my name, phone, and password with ops styling.
- As the platform, I need **inactive** staff blocked from the ops console at the auth gate.

## Acceptance Criteria

1. **`/ops/team`** — admin only (`requireOpsAdminPage`); lists profiles with `role` in `admin`, `dispatcher`.
2. **Invite** — Vestroo-branded email via Resend (`generateLink` + `sendOpsTeamMemberInviteEmail`); role select `dispatcher` | `admin`; default `dispatcher`.
3. **`/ops/team/[memberId]`** — status toggle (`active` / `inactive`); delete with confirm; cannot delete self or last admin.
4. **`/ops/profile`** — staff self-service name, phone, password (patterns from account profile).
5. **Inactive gate** — `requireOpsStaffPage` / `getStaffSession` / `getOpsStaffForAction` redirect or forbid when `profiles.status === 'inactive'`.
6. **Nav** — Configuration → Team (`Users` icon, `visibleRoles: ['admin']`); profile menu → `/ops/profile`; breadcrumb labels `team`, `profile`.
