## Acceptance Criteria (ACs)

1. **Migration file:** New migration named **`YYYYMMDDHHMMSS_ops16_ops_alerts_table.sql`** (timestamp at implementation time; suffix **exactly** **`ops16_ops_alerts_table`**) containing SQL **equivalent** to **[`docs/epic-16.md`](../epic-16.md)** **US-G1** snippet (~352–400):
   - **`create table public.ops_alerts`** with columns:
     - **`id uuid primary key default gen_random_uuid()`**
     - **`kind text not null`** with **`check (kind in (`**  
       **`'maintenance_due',`**  
       **`'license_expiring',`**  
       **`'prdp_expiring',`**  
       **`'quote_expiring_soon',`**  
       **`'email_retry_failed',`**  
       **`'delayed_trip',`**  
       **`'overdue_invoice'`**  
       **`))`**
     - **`severity text not null default 'medium'`** with **`check (severity in ('low','medium','high','critical'))`**
     - **`subject_table text not null`**
     - **`subject_id uuid`**
     - **`payload jsonb not null default '{}'::jsonb`**
     - **`created_at timestamptz not null default now()`**
     - **`acknowledged_at timestamptz`**
     - **`acknowledged_by uuid references public.profiles(id) on delete set null`**
     - **`dismissed_at timestamptz`**
     - **`dismissed_by uuid references public.profiles(id) on delete set null`**
   - **`create index idx_ops_alerts_open`** on **`public.ops_alerts (created_at desc)`** **`where acknowledged_at is null and dismissed_at is null`**
   - **`create index idx_ops_alerts_subject`** on **`public.ops_alerts (subject_table, subject_id)`**
   - **`alter table public.ops_alerts enable row level security`**
   - **`create policy ops_alerts_staff_select`** — **`for select`** **`to authenticated`** **`using (public.is_staff(auth.uid()))`**
   - **`create policy ops_alerts_staff_acknowledge`** — **`for update`** **`to authenticated`** **`using (public.is_staff(auth.uid()))`** **`with check (public.is_staff(auth.uid()))`**
   - **Do not** add **`for insert`** policy for **`authenticated`** (service-role inserts only). Epic comment on **admin dismiss** remains: **server action** + role check; **no** separate **`dismiss`** policy in this migration.
2. **Idempotency / safety:** Prefer **`if not exists`** (or equivalent safe re-run pattern used in sibling **`ops16_*`** migrations) for table, indexes, and policies where the repo standard requires it — without weakening the epic DDL semantics.
3. **`smoke_rls.sql`:** Add a dedicated block (numbered comment consistent with file style, e.g. **“Epic 16 / Story 16.10 — Theme G / US-G1”**) that asserts at minimum:
   - **Service role / bypass path:** an **`INSERT`** into **`public.ops_alerts`** with a valid **`kind`** / **`severity`** fixture **succeeds** (or matches the file’s established “superuser / service” pattern).
   - **Staff positive — SELECT:** under a **staff** JWT / session fixture (**`is_staff`** true), **`SELECT`** returns the inserted row (or expected projection).
   - **Staff positive — UPDATE (acknowledge):** same staff context may **`UPDATE`** **`acknowledged_at`** / **`acknowledged_by`** and satisfies **`WITH CHECK`**.
   - **Negative control (recommended):** **`authenticated`** **non-staff** cannot **`SELECT`** (and optionally cannot **`INSERT`**) per existing smoke style.
4. **Types:** Update **`src/types/database.types.ts`** per repo convention after the table exists (**regen** or **hand-maintained** row type — match **16.9** / project README).
