Payload **keys** must **match** **`15.29`** (**survey**; **do not** invent field names).

5. **Free-pick audit:** Repeat **assign** using **only** the **vehicle picker** (**no** suggestion click) → assert **`assignment_free_pick`** (or **documented** equivalent) on success, consistent with **`15D.3`**.

6. **Sparse / thin historical data:** With **minimal** historic trip / calibration data (**seed** or **env-selected** booking), assert suggestions list is **non-empty** when **`15D.1`** guarantees at least one or at least two rows given at least two eligible vehicles (per **`15.27`** AC wording — **survey**); when the test DB has **fewer than two** eligible vehicles, **document** in spec comment + **Progress Notes** that **empty** list is **acceptable** and assert **panel** **empty state** / copy **without** crash.

Assert **`VehicleSuggestionsPanel`** shows **no** selectable rows **or** a **clear** **empty** / **“no suggestions”** message (**survey** shipped copy). Assert dispatcher **can still assign** via **free-pick** (**US-D1**): picker + **Assign** completes **without** requiring the panel.

8. **`/ops/reports/suggestions` (`15D.4`):** With staff session, open **`/ops/reports/suggestions`**. Assert **staff-only** page loads (**summary** / **table** / **empty state** per **`15.30`**). **Minimum:** **non-error** render; **stretch** within same story: assert **non-zero** counts when **AC3–AC5** ran in **same** test **order** (serial) **if** stable.
