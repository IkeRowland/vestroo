## Story

- As an **algorithm owner** / **ops lead**, I need a **staff-only** **ops** page that **summarises** **suggestion- vs free-pick** **assign** **audit** **rows** for a **rolling** **time** **window** (default **last 30 days**), with **%**, **rank** **aggregates**, and **raw** **counts**, so that **we** can **ground** **calibration** **conversations** in **data** from **`ops_audit_log`**.

## Acceptance Criteria (ACs)

1. **Route and access:** Ship **`/ops/reports/suggestions`** at **[`docs/epic-15.md`](../epic-15.md) §8**: **`src/app/(ops)/ops/reports/suggestions/page.tsx`**. **Admin / staff only** — same **authorization** **intent** as **`/ops/comms`**: **only** users who may use **ops** **intelligence** tools (e.g. **`is_staff`** or the repo’s **established** **staff** check — **survey** `src/app/(ops)/ops/comms/` and **layout** **patterns**). **No** **customer** **portal** or **account** **routes** may **access** this data **through** this page.

2. **Data source — `ops_audit_log`:** Load rows with **`action IN ('assignment_from_suggestion', 'assignment_free_pick')`** and **`created_at`** within the **active** **report** **window** (see **AC3**). Use **server-side** **Supabase** **select** (or a **single** **server** **data** **layer** the page calls). **Field** names in **filters** and **payload** **parsing** must **match** **`15.29`** (see **Prerequisites**; **survey** **migrations** and **implementation**).

3. **Rolling window — default 30 days, configurable:** The report covers **`created_at >= now() - N days`** where **N** defaults to **30**. **Implement** at least one of: a **documented** **code** **constant** (e.g. default `N=30`) **and/or** a **`searchParams`** (or **equivalent**) **query** param for **`days`** (or **similar**) defaulting to **30**. **Document** the **chosen** **mechanism** in **Progress Notes** so **PO** and **ops** know how to read **/ adjust** the window.

4. **Denominator for “% of assignments from suggestions” — pick and document:** The story **MUST** **define** in **Progress Notes** (and **implement** **consistently**) the **set** of rows used for **percentage** **denominators**. **Minimum** **acceptable** **options:** **(A)** only rows with **`action IN ('assignment_from_suggestion','assignment_free_pick')`** (both **combined** as the **relevant** **“calibration** **assign** **audit**” set); or **(B)** a **broader** set if **product** **explicitly** **wants** “**all** assign-**shaped** **audit** **rows**” — **if** (B) is chosen, **list** **which** **`action`** **values** **count** and **why** (must **avoid** **double**-**counting** **the** same **assign** with **other** **audit** **rows**). **Default** **recommendation** in the **epic** is **(A)** **unless** **stakeholders** **agree** otherwise.

5. **Metric — share from suggestions:** For the **chosen** **denominator** (**AC4**), compute the **%** of rows that are **`assignment_from_suggestion`**. If **free**-**pick** **share** is **also** **shown** (suggested for **clarity**), **%**s **MUST** **reconcile** with **raw** **counts** (**AC7**). **Label** the **UI** or **summary** so **readers** know what **“assignment”** means in this **report** (calibration **audit** **rows**, not **necessarily** all **`assign_booking_to_run`** **rows** if **those** are **separate** — **survey** how **`15.29`** **relates** **to** **other** **audit** **lines**).

6. **Metric — rank (suggestion path only):** For rows with **`action = 'assignment_from_suggestion'`** only, compute **average** **`rank`** from **payload** (per **`15.29`**). **Optional** **but** **encouraged** if **low** **effort:** **median** and/or a **small** **breakdown** **(histogram)** of **ranks** **1–3** (or **1–4** if **product** **extends** **ranks** — **survey** **types**). If **no** **suggestion** **rows** in the **window**, **omit** **rank** **summary** or show **N/A** **clearly** (see **AC8**).

7. **Transparency — raw counts:** Display **raw** **row** **counts** for at least: **total** **denominator** **rows** per **AC4**; count **`assignment_from_suggestion`**; count **`assignment_free_pick`** (or **equivalent** **labelling** so **%** and **counts** **match**).

8. **Empty / zero data:** If **no** **rows** **match** the **query** in the **window** (or **denominator** **is** **zero**), the page **MUST** show a **clear** **empty** **state** (e.g. “**No** **calibration** **assign** **audits** in the **last** **N** **days**”) **without** **errors** or **NaN** **%**.

9. **RLS and security:** The **read** path **MUST** **succeed** for **legitimate** **staff** **only** under **current** **Supabase** **RLS** (**survey** **migrations** for **`ops_audit_log`** **staff** **read** as **shipped** with **ops**). **No** new **bypass** of **RLS** for **non**-**staff** **users**.

10. **Ops navigation (survey):** If the **repo** uses a **central** **ops** **nav** **config** (e.g. **`ops-nav-config`** or **sidebar** **manifest** under **`src/app/(ops)`** or **`src/features/ops`**) that lists **`/ops/comms`**-**style** **links**, **add** **`/ops/reports/suggestions`** (label e.g. **“Suggestion** **calibration**” or **“Dispatch** **suggestions** **report**”) so **staff** can **find** the page. If **no** **shared** **nav** **list** **exists**, **add** a **reasonable** **minimal** **discovery** **path** per **E2** (e.g. **link** from an **existing** **ops** **Reports** or **Fulfil** **area** **only** if **that** **pattern** **already** **exists** — **survey** **first**; **do** **not** **invent** a **new** **IA** **without** **aligning** to **`(ops)`** **patterns**).

11. **Optional (not required):** A **server** **action** or **route** **handler** that **returns** **the** **same** **summary** as **JSON** (for a **future** **export** or **API** **consumer**) is **optional**; **page** **render** **satisfies** the **story** without it.
