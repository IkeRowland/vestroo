## Story

- As **ops staff**, I need **`/ops/trips`** in a **split layout** (scannable **trip list** + **detail rail**) with a **clear map placeholder**, **vehicle context**, and **space for trip communications / activity**, so I can **review and act on trips** without losing context on refresh or shared links — using **Vestroo shuttle** vocabulary throughout (**NFR.17.7**).

- As **the codebase**, we need **`/ops/trips`** to **compose** **17.7** + **17.9** per **FE.17.5** and **FE.17.12 item 4**, keeping **RSC-first** data loading and **client** islands only where interaction demands it (**NFR.17.3**).
