## Story

- As a **rider** who opens an **expired or invalid** tracking link, I need a **clear, accessible, non-indexed** page with **trusted contact options** (**email** + **marketing contact**) that **never** exposes trip or personal details, so that **I can reach ops safely** and the product stays aligned with **US-C2** and **Q21**.

## Acceptance Criteria (ACs)

1. **No duplicate UI spec:** Treat **[`TrackTokenInvalidPanel`](../../src/features/rider-tracking/components/TrackTokenInvalidPanel.tsx)** as the **canonical** invalid/expired content unless a **minimal** refactor is required for **a11y** / reuse (e.g. shared wrapper); **document** any copy or markup change in **Progress Notes** vs **15B.3**.

2. **Dedicated route decision (`/track/expired`):** **[`docs/epic-15.md`](../epic-15.md)** §8 once referenced **`.../track/expired/`** (epic path **`(public-ops)`**; **actual** route group today is **`(public-track)`** per **15B.3**). **Either:**
   - **(a)** Add **`src/app/(public-track)/track/expired/page.tsx`** (or agreed group) that renders the **same** panel **without** a **`[token]`** segment (reuse **`TrackTokenInvalidPanel`** + same **`resolveSupportEmailAddress()`** pattern as **[`src/app/(public-track)/track/[token]/page.tsx`](../../src/app/(public-track)/track/[token]/page.tsx)**), **or**
   - **(b)** **Explicitly** record in **Dev guidance** / **Progress Notes** that **`/track/[token]`** with a **known-bad** token is **sufficient** and **`/track/expired`** is **deferred** / **not** product-required (no dead link from emails — riders always have a token string).

3. **Support email / copy alignment:** **Survey** **[`resolveSupportEmailAddress`](../../src/lib/email/email-copy.ts)** (`**SUPPORT_EMAIL**` override, fallback **`support@vestroo.com`**) and the **track** page wiring (**[`src/app/(public-track)/track/[token]/page.tsx`](../../src/app/(public-track)/track/[token]/page.tsx)**). Align panel / page copy with marketing **`/contact`** tone where PO agrees (no new secrets; **no** raw token in UI). **AC:** invalid and optional **`/track/expired`** paths use the **same** support resolution as the valid page (single helper import — **no drift**).

4. **Accessibility:** **Heading order** (e.g. page-level **`h1`** vs panel **`h1`** — avoid duplicate landmark confusion if a layout wraps the panel); **focus** — first meaningful interactive control or **skip** target is sensible on load; buttons/links meet touch target / contrast patterns already used on **`/contact`**. **Survey** marketing contact page for patterns.

5. **Metadata / SEO:** For **error-only** public views, export appropriate **`metadata`** (e.g. **`robots: { index: false, follow: false }`** or equivalent **`noindex`**) on the **invalid** branch and on **`/track/expired`** if implemented — **without** breaking **`force-dynamic`** on **[`src/app/(public-track)/track/[token]/page.tsx`](../../src/app/(public-track)/track/[token]/page.tsx)** (use **`generateMetadata`** or **layout-level** metadata per Next.js **App Router** conventions; **document** choice).

6. **Privacy — US-C2 / Q21:** Response HTML for invalid token **must not** contain **known PII test strings** from seeded trips (e.g. specific driver **full** names, **unmasked** plates, **booking** references) when loaded with a **known-bad** token. **CTA:** assert presence of **“Email support”** (or current button text) **and** link/href to **`/contact`** (or label **“Contact page”** as today). **Defer** deeper scenario matrices to **15B.8** if time — state any deferral in **Tasks** / **Progress Notes**.

7. **Tests — one Playwright spec:** Add **one** **`tests/e2e/`** spec that navigates to **`/track/<knownInvalidToken>`** (e.g. **`invalid.invalid.invalid`** or a **malformed** string that **`verifyRiderTrackToken`** rejects **without** DB access — **survey** **[`src/lib/tracking-tokens.ts`](../../src/lib/tracking-tokens.ts)**) and asserts: **(a)** no PII substrings from a **documented** denylist fixture (or grep-negative for high-risk patterns **listed in the spec comment**), **(b)** CTA affordances per **AC6**. **Not** required to seed Supabase in this story unless already trivial via existing e2e helpers.

8. **Traceability:** Maps to **[`docs/epic-15.md`](../epic-15.md)** **Theme E `15B.7`**, **US-C2**, **Q21** (tokenised, **no auth**, **no** unnecessary exposure on failure).
