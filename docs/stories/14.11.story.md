### US-F1 (full) + §7 — E2E, smoke, unit-in-CI, point_to_point, expiry job assertion strategy

_(Epic **[`docs/epic-14.md`](../epic-14.md)** **§3 Phase 6**; **§4 Theme F — US-F1** **AC1–AC5**; **§7** Definition of Done; **Q13**; **Theme G 14.11**; **§8**.)_

1. **AC1 — Golden path (E2E, US-F1 / §7 “Golden path”):** **CI** has **one** authoritative **passing** spec for the **non-trivial** walk-in **submit → `submitted` → Send quote → `sent` + `expires_at` → accept (or documented primary path) → mocked PayFast → ITN → `ready_to_assign` → “Ready to assign” / `queue=paid` visibility → assign → `trips`**. **May** overlap **14.10** — implementer must **dedupe** (shared helper / extend **14.10** file) or **document** **single** owner; **no** two conflicting “full golden” specs.

2. **AC2 — Reject path (US-F1, §7 “Rejection path”):** **Playwright** covers: customer **reject** link → optional **reason** → **`booking_quotes` `rejected`**, **`bookings` `triaged`** → **ops** shows **`rejected quote`** (or product-equivalent) **badge/indicator** → **Send quote** again → **prior** quote **`superseded`**, **new** quote **`sent`**.

3. **AC3 — Expired path (US-F1, §7 “Expiry path”):** **Playwright** (or **minimal** harness) covers: token with **past `exp`** (or forced **`expired`** page path per product) → **expired** page → **“Request a new quote”** yields a **new** booking — **assert** **new** **`VST-*`** reference and/or **new** row (pattern **TBD** in **Tasks** — DB assert via service role, UI label, or API).

4. **AC4 — Webhook idempotency (US-F1, §6 / §7):** **Duplicate** **COMPLETE**-equivalent **ITN** does **not** create a **second** **trip** / bad **`ready_to_assign`** side effects — **covered in 14.10** or **re-asserted** here; **Progress Notes** name the **owner** spec (prefer **one** file).

5. **AC5 — Token cases (US-F1 + US-B1):** Project **unit** suite (**`src/lib/__tests__/quote-tokens.test.ts`**, **14.2**) **7** cases **green**; **`npm test`** (or the repo’s **documented** unit command) **includes** that file in **CI**. Optional **Playwright** for **invalid** / **malformed** public **`/q/*`** pages **if** not already covered by unit + **thin** E2E gap analysis.

6. **§7 — `point_to_point` (Q13 preserved):** **Regression** test **or** **extend** existing booking E2E: with **QUOTE_FIRST** / **non-trivial** flag context per **Q13**, **`point_to_point`** still reaches **PayFast** (mocked) **and** confirmation path — **no** quote-first branch when **`point_to_point`** + flag **ON** as specified in app (**survey** booking form + env).

7. **§7 — Expiry job (`sent` → `expired`):** **Daily** job behaviour (Epic **13** pattern) is **asserted** via **one** of: extend **`supabase/smoke_rls.sql`** (or **smoke_*.sql**), **SQL** **integration** test, **cron** test hook, or **documented manual** **checklist** + follow-up if **time-based** E2E is infeasible — **choose and record** in **Tasks** / **Progress Notes**.

8. **§7 — Trigger / smoke (duplicate ITN, account no-op):** If **14.1** **smoke** does **not** already cover **duplicate** ITN (handler idempotency is **app**-layer) **+** **account** **no-op** for **`ready_to_assign`**, add **minimal** delta: extend **`smoke_*.sql`** **and/or** **Playwright** **API** **replay** — **survey** **14.1** / current **`supabase/`** smokes first.

9. **US-D2 AC3 — Manual mail (checklist, not E2E):** **Team** verifies **`walk-in-quote`** template in **3 of 4** clients: **Gmail**, **Outlook web**, **Apple Mail** desktop, **iOS Mail** — tracked as a **Task** + **Progress Notes** / **checklist** item (**not** a Playwright AC).
