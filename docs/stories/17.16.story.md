## Story



- As **ops staff**, I need **`/ops/invoicing`** to show a **KPI scorecard row** and a **polished queue table** aligned with **Epic 17** primitives, so I can **see volume and status at a glance** and work the **ready / invoiced / hooks** flows without losing context.



- As **the codebase**, we need **`/ops/invoicing`** to **compose** **`OpsKpiCard`** (**17.4**), **`OpsSparkline`** (**17.5**), and **`OpsStatusPill`** (**17.7**) with **read-only** data loading, **token** hover/row polish, and **documented** URL + parity — **without** changing **RLS** or authorization (**NFR.17.6**).



## Acceptance Criteria (ACs)



1. **KPI row (`OpsKpiCard`):** **`src/app/(ops)/ops/invoicing/page.tsx`** (or extracted server wrapper) renders **three** KPI cards matching **Task 0**-locked labels and **real counts** (see **Reconciliation**); each card uses **`OpsKpiCard`** (**value**, **delta**, **sparkline** per **17.4**/**17.5**), correct **polarity**, and optional **`drillHref`** where epic/dashboard links apply.



2. **Read-only data:** New or extended **loaders** for KPI aggregates are **read-only**, **RLS-respecting**, and follow existing **ops server action** / **`OpsFetchErrorIsland`** error patterns — **no** authz change (**NFR.17.6**).



3. **Layout:** **KPI row** sits below **`OpsPageHeader`** / **`OpsDataFreshnessBar`** / **`OpsInvoicingTabNav`** (exact order **Task 0** — **no** CLS regression); **hooks** tab behaviour unchanged unless **Task 0** explicitly adjusts spacing only.



4. **`OpsStatusPill`:** Queue table **status** (and any **FE.17.8**-appropriate columns per **Task 0**) use **`OpsStatusPill`** + **`getOpsStatusPillTone`** / **`ops-status-pill-tones.ts`**; **no** raw colour-only badges for those columns (**NFR.17.5**).



5. **Table polish:** Data rows use **token** hover (**`bg-ops-accent-soft`** / epic row-hover pattern); **avatars** use **`OpsAvatarCell`** where **17.7** + density apply (**Task 0** column map).



6. **Tab + URL:** **`parseOpsInvoicingTabParam`** / **`OpsInvoicingTabNav`** remain **URL-first**; **`bucket`**/**alias** rules from **Reconciliation** implemented and covered by tests or documented redirects.



7. **Optional `OpsPagination`:** If **17.8** is in scope, integrate **`OpsPagination`** with **`page`/`per`** merged safely with **`tab`** and sort params — **17.10**-style **merge** tests; if **deferred**, parity doc states **follow-up** and **OPS_INVOICING_QUEUE_LIMIT** behaviour stays explicit.



8. **Limit clarity:** **`OPS_INVOICING_QUEUE_LIMIT`** interaction with pagination (if any) is **documented** in parity and **Progress Notes** — **no** silent truncation bugs.



9. **Theme (NFR.17.4):** **`data-ops-theme` light/dark** — no theme branching beyond tokens on new chrome.



10. **Accessibility (NFR.17.5):** **axe** clean on **KPI + table** surfaces; **keyboard** operable interactive controls; **`aria-label`** on icon-only controls.



11. **Copy module (NFR.17.8):** **`src/features/ops/copy/…`** — **single export surface** for page strings, KPI labels, empty/error copy, and **`aria-label`** text introduced or touched by this story.



12. **Parity doc (NFR.17.1):** **`docs/ops-design-system-parity.md`** **§ 17.16** — KPI mapping table, URL params (`tab`, optional **`bucket`/`page`/`per`**), **`OpsStatusPill`** column map, **RSC/client** boundaries.



13. **Tests:** **Vitest** / **RTL** — URL parse/redirect helpers if added; **merge** tests if **`page`/`per`** ship; smoke/a11y for **KPI row** + table where feasible.



14. **`npm run lint`** and **`npm run test`** green.



15. **Tablet / QA:** **`docs/ops-console.md`** (**FE.5.7**) or **Task 0** substitute; record in **Progress Notes**.



16. **Deep link parity:** Epic **FE.17.4** (~131) documents a future drill **`/ops/invoicing?bucket=awaiting`** (paired with a **`loadOpsAwaitingPayment`**-style loader — **not** required to exist before **Task 0**). **Task 0** audits **repo** links (**e.g.** **`OpsInvoicingTabNav`**, **`AccountQueueRowActions`** → **`?tab=ready`**) and implements **`bucket` → `tab`** alias or redirect so **no** broken bookmarks when epic **`bucket`** URLs appear; if **`loadOpsAwaitingPayment`** is added in the same PR, its **`drillHref`** must match the canonical contract (**Reconciliation**).
