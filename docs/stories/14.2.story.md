## Acceptance Criteria (ACs)

### US-B1 — HMAC token module + env + tests (Theme B)

_(Epic **[`docs/epic-14.md`](../epic-14.md)** **§4 Theme B — US-B1**; **Q16**; **§6** risk “HMAC signing key leaked…”; **§7** DoD “Token security”; **§8** paths.)_

1. **Module API:** New module **`src/lib/quote-tokens.ts`** exports **`signQuoteToken(payload)`** and **`verifyQuoteToken(token)`** (see AC2–AC3 for overload/options). **Payload** type **`{ quoteId: string, bookingId: string, purpose: 'accept' | 'reject' | 'pay', exp: number }`** (**trace:** **US-B1** first AC; **Q16** semantics).

2. **Signing:** Uses **HMAC-SHA256** with secret from env **`QUOTE_LINK_SIGNING_KEY`**. Key material must be **≥ 32 bytes** (after decoding — document whether the env value is **raw UTF-8** or **base64** in **Dev Technical Guidance** / **Progress Notes**; must match **`.env.example`** comment). **Missing or weak key** must cause **fail-fast at server startup** (process boot), **not** on first **`signQuoteToken`** call (**trace:** **US-B1** second AC). **Implementation pattern** (e.g. **`instrumentation.ts`**, dedicated **`src/lib/env-quote-tokens.ts`** init imported from instrumentation, or **module-level init** executed on first import from a single bootstrap path): **TBD at implementation** if the repo has no precedent — **AC still requires** validation before serving/handling requests in **Next.js** server runtime.

3. **Verification return type:** **`verifyQuoteToken`** returns a **discriminated union**: **`{ valid: true, payload }`** vs **`{ valid: false, reason: 'expired' | 'invalid_signature' | 'malformed' }`**. Use **`crypto.timingSafeEqual`** (or equivalent) for **constant-time** comparison of the **MAC/tag** (or compare **buffers** derived from the token format — document format in **Dev Technical Guidance**). **Do not** branch on string compare of hex/base64 without timing safety (**trace:** **US-B1** third AC).

4. **Expiry:** **`exp`** is **Unix time in milliseconds**, aligned with **`booking_quotes.expires_at`**: values passed into **`signQuoteToken`** should mirror **`expires_at`** **rounded to the nearest second** (then expressed as ms epoch) so DB and token stay consistent. At verify time, enforce **`exp > Date.now()`** using the **same epoch-ms interpretation** (UTC; **no** local-time ambiguity — document in code comment or story notes). If expired but signature valid → **`{ valid: false, reason: 'expired' }`** (**trace:** **US-B1** fourth AC; **Q16** “Expiry mirrors `booking_quotes.expires_at`”).

5. **Wrong-purpose behaviour (clarifies US-B1 “wrong purpose” test):** **`verifyQuoteToken`** MUST support asserting the token was issued for a **specific** action: either **`verifyQuoteToken(token, options?)`** with **`options.expectedPurpose`** optional, **or** a documented **second form** (e.g. **`verifyQuoteTokenForPurpose(token, expectedPurpose)`**). When **`expectedPurpose`** is provided and the **MAC is valid** and **`exp`** is valid but **`payload.purpose !== expectedPurpose`**, return **`{ valid: false, reason: 'malformed' }`** (semantic mismatch — not signature failure). When **`expectedPurpose`** is **omitted**, verification **only** checks signature, expiry, and that **`purpose`** is one of **`'accept' | 'reject' | 'pay'`**; otherwise **`malformed`**.

6. **Unit tests (`src/lib/__tests__/quote-tokens.test.ts`):** Cover at least these **seven** cases (**trace:** **US-B1** fifth AC; **§7** DoD): **(1)** valid round-trip (sign → verify, **`expectedPurpose`** matches); **(2)** expired (`exp` in the past); **(3)** tampered payload; **(4)** tampered signature; **(5)** truncated token string; **(6)** empty token string; **(7)** **wrong purpose** — e.g. sign with **`purpose: 'pay'`**, verify with **`expectedPurpose: 'accept'`** (must fail per AC5).

7. **Documentation — env var:** **`docs/environment-vars.md`**: add **`QUOTE_LINK_SIGNING_KEY`** to the **Server-only** table with purpose (HMAC for quote deep links), **≥ 32 bytes**, **never `NEXT_PUBLIC_*`**, and **rotation guidance** (rotate on suspected leak; update Vercel + local; invalidate old links — align with **§6** mitigation).

8. **`.env.example`:** Add **`QUOTE_LINK_SIGNING_KEY`** placeholder line (and brief comment: server-only, length, not logged) (**trace:** **§8** References).

9. **§6 mitigation — errors:** Unit tests (or a **dedicated small test** colocated with the module) MUST assert that the **literal secret value** used in tests **never** appears in **`error.message`** for **any** thrown error from **`signQuoteToken` / `verifyQuoteToken` / startup validation** paths (scan thrown errors or `String(err)` as appropriate — **do not** weaken production error messages to satisfy tests). **Environment variable name** may appear in generic “missing env” copy if needed; the **key material** must not (**trace:** **§6** “never echoed in error messages”).

10. **Traceability:** Maps to **[`docs/epic-14.md`](../epic-14.md)** **§3 Phase 2** (token portion), **§4 Theme B (US-B1)**, **Q16**, **§4 Theme G 14.2**, **§5** HMAC row, **§6** key risk, **§7** token-security DoD, **§8** paths.

### Completion Notes List

- **`QUOTE_LINK_SIGNING_KEY`:** Interpreted as **UTF-8 text** (trimmed). Validated with **`Buffer.byteLength(trimmed, 'utf8') >= 32`** (not base64-decoded). Documented in **`docs/environment-vars.md`**, **`.env.example`**, and module JSDoc.
- **Token string:** Same pattern as **`src/lib/dispatch-override-token.ts`**: **`base64url(concat(bodyUtf8, hmacSha256Digest))`**. Canonical JSON uses fixed key order **`quoteId` → `bookingId` → `purpose` → `exp`** so the signed byte sequence is stable.
- **Fail-fast / bootstrap:** Root **`instrumentation.ts`** calls **`registerQuoteLinkSigningKeyFromEnvInInstrumentation()`** when **`process.env.NEXT_RUNTIME === 'nodejs'`**. That helper **skips** during **`NEXT_PHASE`** `phase-production-build` / `phase-export`; **requires** a valid key when **`NODE_ENV === 'production'`** and the key is unset (throws); **no-ops** in non-production when the key is unset so **`next dev`** boots without **`QUOTE_LINK_SIGNING_KEY`**. When a key is present it always runs **`initQuoteLinkSigningKeyAtStartup()`**. **`signQuoteToken` / `verifyQuoteToken`** use the cached secret; if init was skipped they throw a **generic** misconfiguration error (no secret material).
- **Verify order:** Decode → **constant-time** MAC compare on **32-byte buffers** → parse JSON + shape/purpose enum → **`exp <= Date.now()`** → **`expired`** → optional **`expectedPurpose`** mismatch → **`malformed`**.
- **Tests:** Vitest file mirrors **`dispatch-override-token.test.ts`** style (tabs, **`@/`** imports). **`resetQuoteLinkSigningKeyForTests`** exported for test isolation only. Added coverage for **`registerQuoteLinkSigningKeyFromEnvInInstrumentation`** (build-phase skip, production require, development optional).
