## Story

- As an **ops lead**, I need **read-only rendered preview** of each **`comms_templates`** row (**email** HTML + plain text + **SMS** body) **with deterministic seeded variables**, on **`/ops/comms`**, so that **I can validate wording and placeholders before toggling a template active** — **without** editing bodies in the UI, **without** writing template bodies to the DB from this flow, and **without** sending real messages.

## Acceptance Criteria (ACs)

1. **Staff-only preview entrypoint:** From **`/ops/comms`** (post-**`15.21`**), a staff user can open **preview** for a selected template row (by **`id`** plus visible **`event_key`** / **`channel`** alignment). Non-staff **cannot** invoke preview server entrypoints (same **`requireOpsStaffPage` / `getOpsStaffForAction`** patterns as sibling **`(ops)`** mutations). **No** preview-triggered **`comms_*`** **UPDATE**/**INSERT** for template bodies or subject.

2. **Load template by id (staff session):** Server action or route handler loads **`public.comms_templates`** by **`id`** using the **staff** Supabase client; validates **`event_key`** and **`channel`** match the row (or documents single source of truth if UI passes them for display only). On missing row or forbidden access, return a clear error — **no** partial preview.

3. **Seeded substitution map:** Introduce a **central, documented** seed source — e.g. exported **`COMMS_PREVIEW_SEED`** (base key-value record) and/or **per-`CommsEventKey` overrides** merged deterministically — so preview output is **stable in CI** and **does not** use production PII. Document in code comment or adjacent README fragment **only if** the repo already uses short ops docs next to modules; otherwise document in **Progress Notes** / story **Dev Technical Guidance** table.

4. **Placeholder syntax:** Substitution matches **project-real** placeholder conventions used in **`src/lib/email/templates/`**, **booking / quote / trip confirmation**, walk-in quote, etc. (survey existing templates — `{{var}}`, `{{ var }}`, or other — **one** normalisation path). After substitution, **missing** keys (placeholder in template body not present in merged seed map): **leave the literal token unchanged** in the rendered string (e.g. `{{customer_name}}` stays visible) — **this is the chosen product behaviour** for **`15.22`**; document in UI helper text so ops understands unresolved vars.

5. **Email channel preview:** For **`channel = email`** (or equivalent enum): render **HTML** preview using **server-side sanitisation** of the substituted HTML **or** a **sandboxed iframe** with **`sandbox` attributes** appropriate for untrusted-adjacent content; add a **plain-text** tab showing **substituted `body_text` only** — if **`body_text`** is null/empty after load, show an explicit **empty state** (do **not** auto-derive plain text from HTML in this story). **No** external asset loads that weaken isolation unless already standard for ops tools — prefer conservative defaults.

6. **SMS channel preview:** For **`channel = sms`** (or equivalent): show **plain-text** substituted **`sms_body`** with **GSM-7 / UCS-2 segment-aware character and segment count** (or documented approximation if library differs) so ops can judge length; **no** send.

7. **No outbound send:** Preview code path **must not** call Resend, SMS provider, or enqueue outbound comms; grep / architecture note in **Progress Notes** if helpful. Unit or integration test **may** assert the preview module does not import send side-effects (pattern per repo).

8. **XSS / safety:** HTML shown to ops is **not** raw DB HTML in the DOM without mitigation — **sanitise server-side** (allowlist) **or** sandboxed iframe per **AC5**; plain text tab must be **escaped** when rendered as text in React. **Q23** unchanged — preview does not widen who can edit HTML source.

9. **Default: no `ops_audit_log` on preview:** Opening or refreshing preview **does not** write **`ops_audit_log`** unless product explicitly adds `comms_template_previewed` later (out of scope for default).

10. **Traceability & tests:** Maps to **US-B2**, **Theme E `15C.4`**, prerequisites **`15.21`**, **`15.19`**. Add **unit** test(s) that for **one** representative template fixture (inline string or minimal row shape), seeded substitution replaces **known** tokens and leaves an **unknown** token literal per **AC4**. **Epic §6** full-template Playwright **`{{`** absence in **customer-facing** HTML remains **`15C.8`**, not required here.
