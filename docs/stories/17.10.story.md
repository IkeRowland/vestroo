## Story

- As **ops staff**, I need the **bookings queue** to match the **FE.17.12** bar — **refreshed table**, **filters**, **accessible status pills**, and **URL-stable pagination** — so I can **scan and page** bookings efficiently without losing filter context.

- As **the codebase**, we need **`/ops/bookings`** to **compose** **17.7** + **17.8** primitives so later list pages (**17.11+**) inherit the same **URL + visual** contracts.

## Acceptance Criteria (ACs)

1. **Route scope:** Implement UI refresh for **`src/app/(ops)/ops/bookings/page.tsx`** and the **queue table** it composes (e.g. **`BookingsQueueTableRow`**, **`OpsBookingsQueueFilters`**, **`OpsBookingsQueuePresetChips`**, **`OpsTableShell`**, **`ops-primitives`** — **Task 0** confirms exact file list).
2. **`OpsStatusPill`:** Replace **colour-only** chips/badges for **booking / trip / payment** (per **Task 0** column map) with **`OpsStatusPill`** + **visible text**; tones from **`getOpsStatusPillTone`** / **`ops-status-pill-tones.ts`** where applicable (**NFR.17.5**, **17.7**).
3. **`OpsAvatarCell`:** Use for **customer / account identity** columns where **FE.17.12** + Wheelzie **6** density applies — **Task 0** chooses columns (e.g. name + secondary line).
4. **Row hover:** Data rows use **token-only** hover (**`bg-ops-accent-soft`** / epic hover pattern — **NFR.17.4**); no arbitrary hex.
5. **`OpsPagination`:** Integrate **Story 17.8** primitive; **`page`** and **`per`** are **URL-persistent** and **merged** with **`parseOpsBookingsQueueSearchParams`** / **`serializeOpsBookingsQueueSearchParams`** (or extended helpers) — **no regression** on preset chips, **intent**/**status**/**payment**/**client** filters, or **`getIgnoredBookingsQueueParamKeys`** semantics (**NFR.17.6** — presentation + URL only unless **Task 0** files a real bug).
6. **Pagination UX:** **Prev/Next**, page window, **“Results per page”** (**10 / 20 / 50**), and **“Showing x–y of z”** align with **17.8**; browser **back/forward** restores list page state.
7. **RSC-first (NFR.17.3):** Page remains **RSC-first**; **client islands** unchanged or **minimized** — document any new **`'use client'`** boundary in parity **§ 17.10**.
8. **Accessibility (NFR.17.5):** **axe** clean on the **table** surface; **keyboard** operable **filters** and **pagination** (**Tab** / **Enter** / **`aria-label`** on pager controls per **17.8**).
9. **Copy module (NFR.17.8):** Extend **`src/features/ops/copy/…`** for bookings queue strings (**aria-labels**, empty states, pager-adjacent copy if any) — **single export surface**; **Task 0** chooses extend existing file vs new **`ops-bookings-queue-copy.ts`**.
10. **Parity doc (NFR.17.1):** Add/update **`docs/ops-design-system-parity.md`** **§ 17.10** — table layout, **filter row**, **pagination URL matrix** ( **`page`/`per`** + queue keys), **status pill** column map, **`per`**/default **`page`** defaults.
11. **Tests:** **Vitest**/**RTL** per repo patterns — URL **parse/merge** helpers if extracted; **row** test (**snapshot** or **a11y** spot) asserting **pill** visible text; pagination **merge** test covering **preset + page**.
12. **`npm run lint`** and **`npm run test`** green.
13. **Tablet / QA:** Run **`docs/ops-console.md`** checklist (**FE.5.7**) or **Task 0** substitute; record in **Progress Notes**.
14. **Split rail — default out:** **`OpsSplitView`** / booking **detail rail** on list page is **not** in scope unless **PO** expands scope + **17.9** dependency satisfied; otherwise note **defer** to follow-up story.
15. **Walk-in precedent:** **Progress Notes** may note implications for **`/ops/walk-in`** (**FE.17.12** item **3**) — no walk-in implementation in **17.10**.
16. **Query semantics:** **No** RLS or Supabase query **meaning** change unless **Task 0** documents a pre-existing defect with **test** or **ticket** reference (**NFR.17.6**).
17. **Story maintenance:** On completion, dev agent updates **Status**, **Tasks**, **Progress Notes**, **DoD report**, per **[`.cursor/rules/story-completion-dev-agent.mdc`](../../.cursor/rules/story-completion-dev-agent.mdc)**.
