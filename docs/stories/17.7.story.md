## Story

- As **ops staff**, I need **status chips** and **avatar+name cells** that match the Wheelzie **1** / **3** / **6** row language, with **readable text** beside tone, so I can **scan booking/trip/roster state** without misreading color alone.

- As **the codebase**, we need **`OpsStatusPill`**, **`OpsAvatarCell`**, and **`ops-status-pill-tones.ts`** as **shared primitives** so **17.10+** list pages **never disagree** on status→tone mapping (**epic acceptance**).

## Acceptance Criteria (ACs)

1. **`OpsStatusPill`:** Implemented at agreed path under **`src/features/ops/components/`** (e.g. **`OpsStatusPill.tsx`**) with props: **`tone: 'success' \| 'warning' \| 'danger' \| 'info' \| 'neutral'`**, **`dot?: boolean`** (default **`true`**), **`children: ReactNode`** (**required** — see Reconciliation).
2. **`OpsStatusPill` visual:** **`rounded-full`**, **`px-2 py-0.5`**, **`text-[11px] font-medium`**, **tone**-derived **soft tint** on background + foreground using **17.1** ops token pattern (e.g. **`bg-ops-success/10 text-ops-success`**, analogous classes per tone — **NFR.17.4**, **no** hard-coded hex).
3. **OpsStatusPill — accessibility (NFR.17.5):** Pills **MUST NOT** communicate state **by color alone** — **`children`** carries **visible redundant** status/descriptor text; if **`dot`** is decorative, it does **not** replace text semantics (**Task 0** documents **`dot={false}`** when text alone is enough vs compact tables).
4. **`OpsAvatarCell`:** Props **`src?: string`**, **`name: string`**, **`secondary?: string`** (e.g. email). **32px** circular avatar; **`name`** **semibold**; **`secondary`** **muted** typography using ops tokens.
5. **`OpsAvatarCell` initials:** When **`src`** is absent/invalid, show **deterministic** initials fallback from **`name`** per **Reconciliation** algorithm; **test** golden vectors.
6. **`ops-status-pill-tones.ts`:** Single file at **`src/features/ops/ops-status-pill-tones.ts`** (exact epic path) exporting the **canonical** **status string → `OpsStatusPill` tone** mapping for the epic table: **`on_trip`→info**, **`assigned`→info**, **`awaiting_assignment`→warning**, **`cancelled`→danger**, **`completed`→success**, **`paid`→success**, **`awaiting_payment`→warning**, **`overdue`→danger**, **`on_duty`→info**, **`off_roster`→neutral**.
7. **Unknown status:** Behaviour per **Reconciliation** row (**neutral** + chosen warning policy); **Vitest** covers **unknown** input.
8. **Vitest (`ops-status-pill-tones.ts`):** **Every** epic table row + **unknown** + any **extra** domain keys **Task 0** adds after audit — all asserted to expected tone.
9. **Component tests:** **RTL** (or **component tests**) for **`OpsStatusPill`** — visible **`children`** text; **`dot`** presence when default **`true`** and absence/suppression when **`dot={false}`** per implementation (**Task 0** defines DOM contract).
10. **Component tests:** **RTL** for **`OpsAvatarCell`** — initials from **`name`** cases; **`secondary`** text when provided; image/alt behaviour per **Task 0** if **`src`** set.
11. **RSC-first (NFR.17.3):** Primitives default to **Server Components**; **`'use client'`** only on the **smallest** file boundary **if** **Task 0** requires client-only image/interaction — document rationale in parity **§ 17.7**.
12. **Light/dark (NFR.17.4):** All colors/spacing use **ops tokens / Tailwind ops utilities** only — verify under **`data-ops-theme="light"`** and **`dark`** in **Progress Notes** (spot-check).
13. **Copy (NFR.17.8):** **`children`** is typically supplied by **parent** (table row). Add **`ops-status-pill-copy.ts`** **only if** this story introduces **visible strings** beyond **`children`**; if added, **single module** per surface rule — otherwise **document** “no pill copy module” in parity.
14. **Documentation (NFR.17.1):** Extend **`docs/ops-design-system-parity.md`** with **§ 17.7** — props tables, **mapping table** (mirror epic), **a11y**, **`dot={false}`** guidance, **`next/image`** vs **`<img>`** decision, initials spec.
15. **Scope + quality:** **Primitives + mapping + tests + docs** satisfy DoD; **wiring** into **`/ops/*`** tables is **optional minimal** smoke **only** if **Task 0** adds **one** demo row — default **no** production table refit in **17.7**. **`npm run lint`** and **`npm run test`** green after implementation.
