## Story

- As **ops staff with old bookmarks**, when I open **`/ops/fulfil`** or **`/ops/fulfil?queue=…`**, I am **temporarily redirected (302)** to **`/ops/walk-in`** on the correct **stage** tab, so I land on the **current** walk-in queue without broken links (**Q18**).

- As **the product owner**, I need **board / trips / calendar** URLs to **keep working** without this story adding redirects there, so trip-centric bookmarks stay valid per epic **non-goals**.

## Acceptance Criteria (ACs)

1. **Redirect map:** Requests to **`/ops/fulfil`** and **`/ops/fulfil?queue=paid`** respond with **302** and **`Location`** targeting **`/ops/walk-in?stage=ready_to_assign`** (path + query; allow stable encoding per Next **URL** APIs).
2. **`trip_request`:** **`/ops/fulfil?queue=trip_request`** → **302** to **`/ops/walk-in?stage=new`**.
3. **`pending`:** **`/ops/fulfil?queue=pending`** → **302** to **`/ops/walk-in?stage=awaiting_payment`**.
4. **Non-goals:** **`/ops/board`**, **`/ops/trips`**, **`/ops/calendar`** are **not** redirected by this story’s logic (no new **302** from this feature for those paths).
5. **Temporary:** All fulfil legacy redirects use **302**, not **301**.
6. **E2E:** **`tests/e2e/legacy-url-redirects.spec.ts`** asserts **302** (or non-followed redirect) **and** correct **`Location`** (or equivalent) for **each** mapping in AC1–AC3; Vitest suite (**`npm run test`**) stays green — run Playwright via **`npm run test:e2e -- tests/e2e/legacy-url-redirects.spec.ts`** when validating E2E locally / CI.
7. **Quality:** **`npm run lint`** remains green.
