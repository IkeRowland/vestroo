## Reconciliation (mandatory)

| Issue | Resolution |
|-------|------------|
| **SVG `viewBox` vs `width` / `height` props** | Expose **`width`** and **`height`** as the **layout box** (attributes on **`<svg>`** for predictable SSR layout). Use a **fixed `viewBox`** (e.g. **`0 0 W H`** matching internal coordinate system) **or** derive **`viewBox`** once from props in a **pure** function so the same **`points`** / **`series`** always yield the same path **d** strings — **Task 0** locks one pattern for all four components and documents it in parity **§ 17.5**. **No** `%`-based SVG sizing that causes re-flow on rerender. |
| **Donut center label slot (SSR)** | **`center` slot** is **`ReactNode`** (epic: center label slot). Must render **without client hooks** — plain children or **`props.children`** / named slot prop; **no** `useState` / `useId` **unless** justified for a11y and **isolated** (prefer **deterministic** `id` from props or omit decorative-only ids). **Task 0** confirms **RSC** composition pattern (e.g. parent passes **`<span className="…">`**). |
| **Bar chart: zero / negative handling** | **`up`** / **`down`** represent **stack segments** (Done vs Cancelled). **Task 0** defines: **(a)** both **≥ 0** only — **clamp** or **assert** in dev; **(b)** if negatives appear from bad data, **floor at 0** for bar length **or** show **empty state** — pick one and test. **X-axis** labels remain **text** (not color-only). |
| **Snapshot stability (float formatting)** | Deterministic output for given input: **avoid** locale-dependent **`toFixed`** surprises if tests run in multiple locales **or** centralize number→string for path generation in one helper with **explicit** rounding (e.g. fixed precision) — **Task 0** documents. **SVG path** commands should not drift from floating noise (normalize domain/range math). |
| **`tone` → `--ops-chart-N` mapping (single source of truth)** | Implement **`ops-chart-tones.ts`** (or **`ops-chart-utils.ts`** colocated) exporting a **single map**: **`accent` \| `success` \| `warning` \| `danger` \| `muted`** → **chart token index 1–6** (or direct **`hsl(var(--ops-chart-N))`** resolver). Components **must not** duplicate tone→color logic. **No hard-coded hex** in **`.tsx`** — use **`currentColor`**, **`className`** with **`text-ops-chart-*`**, or **`style={{ color: 'hsl(var(--ops-chart-N))' }}`**. |
| **Relationship to story 17.4 Option B (`sparkline` slot)** | **17.4** ships **`OpsKpiCard`** with optional **`sparkline?: React.ReactNode`** and reserved **56–72px** band. **17.5** delivers **`OpsSparkline`** to **fill** that slot; wiring **`OpsSparkline`** into **`OpsKpiCard`** consumers may land in **17.6** or **follow-up** — this story **owns primitive quality**; dashboard wiring is **not** required for **17.5** DoD unless **Task 0** expands (default: **primitives + tests + docs only**). |

## Story

- As **ops staff**, I need **small charts and sparklines** that respect **light/dark** ops themes and **screen readers**, so I can **scan trends** on the dashboard without relying on color alone.

- As **the codebase**, we need **snapshot-stable, RSC-first SVG primitives** (**`OpsSparkline`**, **`OpsBarChart`**, **`OpsDonutChart`**, **`OpsAreaChart`**) with a **shared tone→token map** and **copy-module** empty states, so **17.6** and future **`/ops/*`** surfaces can compose charts **without** adding **Recharts** (**Option A**).

## Acceptance Criteria (ACs)

1. **Implementation scope:** **Option A only** — pure SVG in **`src/features/ops/components/`** (and optional colocated **`ops-chart-utils.ts`** / **`ops-chart-tones.ts`**). **Do not** add **Recharts** or other **large** chart libraries (**NFR.17.2**).
2. **`OpsSparkline`** at **[`src/features/ops/components/OpsSparkline.tsx`](../../src/features/ops/components/OpsSparkline.tsx)** — props: **`points: number[]`**, **`width: number`**, **`height: number`**, **`color?: string`** (default resolves to **`--ops-accent`** / agreed token pattern), **`ariaLabel: string`**. Renders **line + filled area**; **deterministic** path from **`points`**; layout **stable** (no re-flow on rerender — see Reconciliation).
3. **`OpsBarChart`** at **[`src/features/ops/components/OpsBarChart.tsx`](../../src/features/ops/components/OpsBarChart.tsx)** — props: **`series: { label: string; values: { x: string; up: number; down: number }[] }`**, optional **`legend`**. **Stacked bars** (**up** vs **down** segments — Done vs Cancelled pattern); **x** labels and **legend** text carry semantic meaning (**axe** / **NFR.17.5**).
4. **`OpsDonutChart`** at **[`src/features/ops/components/OpsDonutChart.tsx`](../../src/features/ops/components/OpsDonutChart.tsx)** — props: **`slices: { label: string; value: number; tone: 'accent' \| 'success' \| 'warning' \| 'danger' \| 'muted' }[]`**, **center label slot** (composition API per Reconciliation). Visual cue per Wheelzie image **10** donut. **Slice labels** redundant to color.
5. **`OpsAreaChart`** at **[`src/features/ops/components/OpsAreaChart.tsx`](../../src/features/ops/components/OpsAreaChart.tsx)** — props: **`points: { x: string; y: number }[]`**, **`ariaLabel: string`**. Filled area / line cue per Wheelzie image **10** earnings pattern; deterministic geometry.
6. **Server Component compatibility:** All four components **MUST** be renderable as **RSC** — **no `useState`** (or other client-only hooks) on the **render path**; **pure props → SVG**.
7. **Accessibility:** Each chart exposes a **meaningful** summary: root **`<svg role="img" …>`** (or equivalent) with **`aria-label`** built from props **or** consumer-provided **`ariaLabel`** where epic shows dynamic summaries (e.g. *"Earnings summary, peaking at R18,450 in April"* — pattern, not literal requirement). **Bar/donut:** screen readers get **textual** category + value context — **Task 0** lists exact **`aria`** pattern. **axe:** no **color-only** semantics (**NFR.17.5**).
8. **Empty state:** When **`points.length === 0`** (**`OpsSparkline`**, **`OpsAreaChart`**) or **bar/donut equivalents** (no slices / all values zero — **Task 0** defines predicates), render small text **exactly** **`No data for this period.`** via **`src/features/ops/copy/ops-charts-copy.ts`** (**NFR.17.8**).
9. **Theming (NFR.17.4):** Colors from **`--ops-chart-1`** … **`--ops-chart-6`**, **`currentColor`**, and/or **`style={{ color: 'hsl(var(--ops-chart-N))' }}`** / Tailwind **`text-ops-chart-*`** — **no hard-coded hex** in chart **`.tsx`** files.
10. **Documentation:** Add **[`docs/ops-design-system-parity.md`](../ops-design-system-parity.md)** **§ 17.5** — props tables, **a11y** notes, empty states, token mapping, **Wheelzie 6 / 10** references; include **Dependency inventory § 17** note: **Option B** / **`/ops/reports/*`** Recharts path **deferred** (parity with epic **§ Route rollouts** item **14** / **~323**).
11. **Copy (NFR.17.8):** **`src/features/ops/copy/ops-charts-copy.ts`** (or **`ops-chart-copy.ts`** — **Task 0** picks **single** export surface) holds **`No data for this period.`** and any **shared chart chrome** strings introduced here.
12. **Tests:** **Snapshot tests** (or equivalent **deterministic** SVG string assertions) for **each** primitive with **fixed** props; tests for **empty state** copy; unit test **tone → chart token** map; **axe** test hookup per repo convention (**Vitest** + **jest-axe** or existing pattern — **Task 0** confirms).
13. **Quality:** **`npm run lint`** and **`npm run test`** green after implementation.
