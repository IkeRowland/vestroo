## Story



- As a **booker** (and indirectly as a **rider**), I need a **signed tracking URL** included in the **trip confirmation** email when a quote is sent / trip is confirmed, so that **someone without a portal account** can open **`/track/...`** later (**15B.3**) using a **time-bounded HMAC token** — aligned with **US-C1** and **Epic 14** signing.



## Acceptance Criteria (ACs)



1. **HMAC module — `purpose: 'rider_track'`:** Add **`signRiderTrackToken` / `verifyRiderTrackToken`** (names may vary but behaviour fixed) with payload shape **`{ trip_id: string, purpose: 'rider_track', exp: number }`** where **`exp`** is UTC epoch **milliseconds** (consistent with **`quote-tokens.ts`** / **`account-invite-tokens.ts`** “same wire shape”: canonical JSON key order, **`Buffer.concat([bodyUtf8, hmacSha256])`** → **base64url**). **`verify`** returns discriminated union: valid / **`expired`** / **`invalid_signature`** / **`malformed`**, analogous to **`verifyQuoteToken`**. **No** `trip_id` / MAC logging in production paths.



2. **Signing key — env:** Use **`QUOTE_LINK_SIGNING_KEY`** (same as quote deep-links — **[`.env.example`](../../.env.example)**). **Survey** **`initQuoteLinkSigningKeyAtStartup`** / **`registerQuoteLinkSigningKeyFromEnvInInstrumentation`** in **`instrumentation.ts`**: rider token mint on the server must only run when the key is initialised the same way as quote signing (tests may call the same init helpers as **`src/lib/__tests__/quote-tokens.test.ts`**). **Optional follow-up** (document in Progress Notes if skipped): a dedicated **`VESTROO_RIDER_TRACK_SIGNING_KEY`** — **not** required for **15B.2** unless security review demands key separation.



3. **Computing `exp` — US-C1 vs Q21:** **Mint rule (normative for this story):** **`exp_ms = ms(time_end_estimate) + 2 hours`**, using the **same primary trip** resolution as trip confirmation today (**`firstTripFromBooking`** / **`booking_trips.sort_order`** in **[`src/lib/account-trip-confirmation-email-data.ts`](../../src/lib/account-trip-confirmation-email-data.ts)**). **Survey DB:** **`public.trips.time_end_estimate`** is **`timestamptz NOT NULL`** (see e.g. **[`supabase/migrations/20260402131427_vin_shuttle_driver_and_on_demand_trips.sql`](../../supabase/migrations/20260402131427_vin_shuttle_driver_and_on_demand_trips.sql)**). **Extend** **`BOOKING_TRIP_CONFIRMATION_MAIL_SELECT`** in **[`src/lib/booking-quote-trip-confirmation-email.ts`](../../src/lib/booking-quote-trip-confirmation-email.ts)** and the parallel **`BOOKING_MAIL_SELECT`** in **[`src/actions/bookingQuoteOps.ts`](../../src/actions/bookingQuoteOps.ts)** so the embed includes **`trips.time_end_estimate`** (currently selects **`id, time_start_estimate, chauffeur_id, …`** only — **required** for AC). **Reconcile epic wording:** **[`docs/epic-15.md`](../epic-15.md)** **Q21** says token expires **2h after trip `completed`**; **US-C1** says **`exp = trip.time_end_estimate + 2 hours`**. **This story implements US-C1 literally** for the signed `exp` field. **Document in Dev guidance / Progress Notes:** **15B.3** must treat **`exp`** as the hard expiry for verification; if product later needs completion-relative windows, that is a **separate** design (re-mint, longer cap, or ops SLO on estimates) — **not** **15B.2** unless PO reopens.



4. **Mint at trip confirmation path:** When **`buildAccountTripConfirmationProps`** (or a thin helper it calls) assembles props for **[`renderAccountTripConfirmationHtml`](../../src/lib/email/templates/account-trip-confirmation.ts)**, **mint** the token if: primary trip has **`id`** and parseable **`time_end_estimate`**, and signing key is available. Build absolute URL **`${appOrigin}/track/${token}`** using **`NEXT_PUBLIC_APP_URL`** (trim trailing slash; same pattern as other deep links — **survey** quote / invite URL builders). **Wire** through **`src/actions/bookingQuoteOps.ts`** **`sendBookingQuote`** render branch, **`resolveRenderedTripConfirmationHtmlForSentQuote`** in **[`src/lib/booking-quote-trip-confirmation-email.ts`](../../src/lib/booking-quote-trip-confirmation-email.ts)**, and **[`src/actions/retrySendBookingQuoteEmail.ts`](../../src/actions/retrySendBookingQuoteEmail.ts)** so retries / backfill get the **same** HTML rules.



5. **Email template — `riderTrackingUrl` (optional prop):** Extend **`AccountTripConfirmationProps`** with optional **`riderTrackingUrl?: string | null`**. When **set**, render a clear **“Rider tracking”** (or equivalent) section with a **single** clickable link. **Visibility rules (explicit):** **Always** include the tracking URL in the **booker** trip confirmation email when mint succeeds (US-C1: booker can **forward** if **`rider_email`** is unset). When **`rider_email`** is **non-empty**, add short copy that the link can be **shared with the rider** (wording product-safe). When mint **cannot** run (missing trip/end estimate, or signing not configured in dev), **omit** the section — **no** broken link.



6. **Types / PII:** Extend **`BookingForTripConfirmationEmail`** / **`BookingTripConfirmationSendRow`** in **`account-trip-confirmation-email-data.ts`** only as needed for **`rider_*`** and embedded **`time_end_estimate`** (after select widening). Do **not** log token or rider PII in **`console.*`**.



7. **Tests:** Add **`src/lib/__tests__/tracking-tokens.test.ts`** (or name aligned with module) covering: sign→verify round-trip; wrong MAC; **`exp`** in the past → **`expired`**; **`expectedPurpose: 'rider_track'`** enforcement if implemented. Extend **[`src/lib/email/__tests__/account-trip-confirmation.test.ts`](../../src/lib/email/__tests__/account-trip-confirmation.test.ts)** (or equivalent) asserting HTML contains the link when **`riderTrackingUrl`** passed. Update **[`src/actions/__tests__/bookingQuoteOps.test.ts`](../../src/actions/__tests__/bookingQuoteOps.test.ts)** expectations if rendered HTML / idempotent send assertions reference trip confirmation body — **survey** existing **`Trip confirmation`** string assertions.



8. **Traceability:** Maps to **[`docs/epic-15.md`](../epic-15.md)** **Theme E `15B.2`**, **US-C1** (token mint + email), **§8** 15B shared lib path.
