## Story

- As **a traveler on slide 3**, I see a **compact** phone row (**flag + dial code** + national digits) with a **sensible default** (**FE.19.2**, typically **`+27`**), and I open the **full country list only when I need to change country** (**FE.19.7**).
- As **a traveler on a slower connection**, I want the **heavy country dataset** deferred until I **open** the selector, so initial slide **3** paint stays light (**NFR.19.1**, epic **AC**).
- As **ops / data integrity**, I need the same **E.164** validation path and **`tripRequestPassengerFieldsSchema`** rules as today (**NFR.19.6**).

## Acceptance Criteria (ACs)

1. **Default country:** Initial dial / country reflects **FE.19.2** inference (**`phoneCountryIso2Hint`** → **`passengerCountryIso2`**, fallback **`za`** — typically **`+27`**); user can change before submit.

2. **Flag + dial trigger:** Visible control shows **flag** (or agreed visual) **and** **dial prefix** for the selected **`iso2`**; activating it opens a **Radix `Popover`** (via **`@/components/ui/popover`** or equivalent Radix wrapper) — **not** an always-on expanded combobox in the main column (**epic** lines **148–149**).

3. **Lazy data:** **`country-telephone-data`** is **not** loaded until the user **opens** the country popover (first interaction); list UI / heavy child ships behind **`next/dynamic`** so the **download** of that chunk **and** **`loadTripRequestCountryOptions`** align with **open**, not slide **3** mount (**epic** lines **156–157**, **NFR.19.1**).

4. **Validation unchanged:** **`libphonenumber-js`** via **`passengerPhoneToE164`** / **`tripRequestPassengerFieldsSchema.superRefine`** — same error semantics for invalid national numbers (**epic** line **150**).

5. **`onBlur` hint:** Where **`libphonenumber-js`** can format a **valid** national number for the selected country, apply **read-friendly** national formatting **on blur** of the national phone field (optional helper text or reformatted value — **epic** line **150**).

6. **Accessibility:** Popover **trigger** and list remain **keyboard** operable; visible **labels** preserved (**NFR.19.2**); **`aria-live`** for load errors inside popover if product requires.

7. **Tests:** **`tripRequestPassengerFieldsSchema`** / **`passengerPhoneToE164`** tests in **[`trip-request-submit-schema.test.ts`](../../src/features/booking/components/trip-request/trip-request-submit-schema.test.ts)** stay **passing**; add/adjust RTL tests for **deferred** load (e.g. no `loadTripRequestCountryOptions` call until open), **Popover** open/close, and default **dial** display; **`npm run test`** / **`npm run lint`** green for affected suites.
