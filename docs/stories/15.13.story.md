## Story

- As a **rider** (or anyone with a valid tracking link), I need a **public, no-login** page at **`/track/[token]`** that shows a **milestone timeline** and **minimal** trip/driver/vehicle context, so that I can see **progress** toward pickup and completion **without** exposing unnecessary personal data when the link is wrong or expired (**US-C1**, **US-C2**, **Q21**).

## Acceptance Criteria (ACs)

1. **Route + layout survey:** Add **`src/app/.../track/[token]/page.tsx`** (and optional **`loading.tsx`** / **`error.tsx`**) at URL **`/track/[token]`**. **Survey** Epic **14** precedent **`(quote)/q/[token]/*`** ([**`src/app/(quote)/q/[token]/accept/page.tsx`](../../src/app/(quote)/q/[token]/accept/page.tsx)**) for **`dynamic = 'force-dynamic'`**, **`params: Promise<{ token }>`**, and route-group placement. Epic §8 suggests **`(public-ops)/track/...`** — **pick** **`(quote)`**, **`(app)`**, or a **new** `(public-track)` group consistent with marketing/SEO and **no** accidental auth shell; **document** the choice in **Progress Notes**.

2. **Token gate — defence in depth:** On each request, **`verifyRiderTrackToken(rawToken)`** from **[`src/lib/tracking-tokens.ts`](../../src/lib/tracking-tokens.ts)**. **Only** if result is **`{ valid: true, payload }`** **and** server-side **`exp`** is still in the future (consistent with **`verify`**’s **`expired`** handling), proceed to load **`trips`** (and related rows) for **`payload.trip_id`**. For **`invalid_signature`**, **`malformed`**, or **`expired`** (or **`valid: false`**), **do not** query booking/chauffeur/vehicle for display — render the **non-PII** state only (**AC9**). **No** logging of raw token, MAC, or **`trip_id`** on failure paths.

3. **Data loading — minimal fields, server-only secret:** After a **valid, unexpired** token, fetch trip + booking + chauffeur + vehicle using **server-only** access (**[`createServerClient`](../../src/lib/supabase/server.ts)** in **[`src/lib/supabase/server.ts`](../../src/lib/supabase/server.ts)** is the existing service-role pattern) **or** a **`SECURITY DEFINER`** RPC that internally checks the same token payload — **pick one** and document. **AC:** selects return **only** fields required for **US-C2** UI (status/timestamps, **`time_start_estimate`** for en-route pickup context, driver first name, vehicle make/model/colour, plate string for masking, optional driver photo URL/key if stored, booking confirmation signal if needed for “Booking confirmed” milestone). **Do not** return booker/rider name/email/phone to the client for this page unless epic explicitly requires it for the milestone view (**default: no**).

4. **Milestone timeline (US-C2):** Render ordered milestones: **Booking confirmed** → **Driver assigned** → **Driver en route** → **Driver arrived** → **Trip completed**, with **current** / **future** / **past** visual styling and **timestamps** when the system has a trustworthy time for each step. **`en_route`** milestone copy must surface **pickup context** using **`time_start_estimate`** (label/format consistent with existing ops/field copy). **Survey** **`TripFulfilmentStatusDb`** in **[`src/types/database.types.ts`](../../src/types/database.types.ts)** and fulfilment vocabulary in **[`src/app/(field)/field/trips/[tripId]/page.tsx`](../../src/app/(field)/field/trips/[tripId]/page.tsx)** / **[`src/lib/chauffeur-trip-transitions.ts`](../../src/lib/chauffeur-trip-transitions.ts)**. If **`arrived`** is **not** a distinct DB status, **document** the product mapping (e.g. UI-only step, collapse, or follow-up migration) in **Dev guidance** — **do not** silently invent DB values.

5. **Driver / vehicle card:** Show chauffeur **first name** only; vehicle **make / model / colour**; **plate masked** as **first two characters + `***`** (normalize case/spacing); **photo** when a file/URL exists on the chauffeur record (survey schema). **“Call driver”** (e.g. `tel:`) only when **ops/product rules permit** — **survey** **[`src/lib/field-customer-contact.ts`](../../src/lib/field-customer-contact.ts)** (`tripStatusAllowsCustomerContact`, masking helpers) and any ops/env toggles; if no rider-specific flag exists, **default conservative** (e.g. same status gate as field customer contact) and note in **Progress Notes**.

6. **Live updates:** Client **polls** trip snapshot **every 30 seconds** while the page is open and token is treated as valid for that session. **Additionally**, subscribe to **Supabase Realtime** on the **`trips`** row (or an existing notification channel) **when** the project already supports it for trip status — **graceful no-op** if Realtime is unavailable (no user-visible error loop). **Survey** **[`docs/realtime-and-notifications.md`](../realtime-and-notifications.md)** if present.

7. **Cancelled / edge trips:** If **`trips.status === 'cancelled'`** (per **`TripFulfilmentStatusDb`**), show a clear **cancelled** outcome on the timeline/card **without** leaking unrelated PII; still respect token expiry.

8. **Middleware:** **`/track`** must **not** require Supabase session refresh unless product decides otherwise — **survey** **[`middleware.ts`](../../middleware.ts)** (today only **`/ops`**, **`/field`**, **`/account`** attach **`refreshSupabaseSessionCookie`**). **AC:** **`/track/*`** stays **anonymous-friendly** (no forced login).

9. **Expired / invalid token UX (US-C2 + 15B.7 handoff):** Dedicated polite page: message that the link **expired or is invalid**, **no personal data** (no driver, no plate, no booking refs). **CTA** to **contact ops** (support email/phone from existing site constants or marketing contact — **survey** footer/contact components). **15B.7** may add **Playwright** / privacy suites on top — **15B.3** still ships this UX.

10. **Tests:** Unit tests for pure helpers (milestone mapping, plate mask, “should show call” predicate if extracted). **Integration** or **RSC-level** tests optional if brittle; minimum **Vitest** coverage for token-gated loader logic **mocking** Supabase. **No** full **15B.8** E2E in this story unless trivial.

11. **Traceability:** Maps to **[`docs/epic-15.md`](../epic-15.md)** **Theme E `15B.3`**, **US-C1** / **US-C2**, **Q21**; explicitly **not** **Q22** map (**15B.5**).

### Implementation notes

- **POPIA:** Treat the token as the **only** bearer credential; wrong MAC = **same** expired-style UX as unknown trip (**no** oracle differences that leak existence of trips).
- **Service role:** Narrow selects and **avoid** re-exporting raw rows to client components — prefer **DTO** shapes passed as props.
- **Real-time:** If subscription setup is non-trivial, ship **poll-only** first behind a small abstraction so Realtime can be toggled on without rewriting the page (**document** in **Progress Notes** if deferred).
