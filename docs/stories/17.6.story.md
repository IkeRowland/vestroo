## Story

- As **ops staff**, I need the **`/ops` home** to present a **Wheelzie image 10–style** **scorecard grid** with **inline sparklines** and **at-a-glance charts**, so I can **scan operations health** without drilling into every route.

- As **the codebase**, we need **`src/app/(ops)/ops/page.tsx`** and **`OpsDashboardView`** to compose **`OpsKpiCard`** (**[`docs/stories/17.4.story.md`](./17.4.story.md)**) with **`OpsSparkline`** in the sparkline slot (**[`docs/stories/17.5.story.md`](./17.5.story.md)**), plus chart regions (**`OpsDonutChart`**, **`OpsAreaChart`**, optional **`OpsBarChart`**), while **preserving** **`OpsDataFreshnessBar`**, **`OpsFetchErrorIsland`**, and **`OpsPageHeader`** behaviour — **restyled** to **17.1** tokens / density (**NFR.17.4**).

## Acceptance Criteria (ACs)

1. **Layout:** **`src/app/(ops)/ops/page.tsx`** and **`src/features/ops/components/OpsDashboardView.tsx`** deliver a **Wheelzie image 10–inspired** dashboard **layout**: **scorecard grid** of **`OpsKpiCard`** rows/columns appropriate for **`md`–`2xl`**; **`NewBookingsHomeCard`** remains **first-class** and **does not** regress visually vs **17.4** (spot-check + test).
2. **Sparklines:** Every in-scope **`OpsKpiCard`** that has a **numeric trend series** from **`loadOpsDashboardKpis`** (or agreed shape) renders **`OpsSparkline`** in the **`sparkline`** slot with a **meaningful `ariaLabel`** from copy (**17.5** / **NFR.17.5**).
3. **Charts (FE.17.12):** Dashboard includes **at least one** **`OpsDonutChart`** region and **at least one** **`OpsAreaChart`** region; props and **titles** match **Task 0** + **[`docs/design/visual-redesign-references.md`](../design/visual-redesign-references.md)** mapping (**§ `/ops`**, ~36–38). **`OpsBarChart`**: **optional** per Reconciliation — if omitted, document in parity **§ 17.6**.
4. **Data wiring vs MVP:** Implement **exactly one** of **MVP A / B / C** from the Reconciliation table; **all** implemented loaders (**MVP A** or **17.6a**) MUST be **read-only**, **RLS-respecting**, and on failure surface **`OpsFetchErrorIsland`** with **correlation id** when available (**FE.17.4** / existing patterns in **`loadOpsDashboardKpis`**).
5. **`loadOpsDashboardKpis`:** Continue to drive all KPI tiles **already** backed by this loader; **no regression** in error / empty handling.
6. **Chrome preservation:** **`OpsDataFreshnessBar`**, **`OpsFetchErrorIsland`**, **`OpsPageHeader`** — **same props contracts** and **user-visible behaviour** (errors, timestamps); **visual** refresh only (spacing, typography, borders) using **17.1** tokens.
7. **RSC-first (NFR.17.3):** **`OpsDashboardView`** remains a **Server Component** by default; **`'use client'`** only where interaction requires it (e.g. optional **motion** wrapper — smallest island).
8. **Motion:** Either **~200ms CSS** transitions on cards/sections **or** subtle **`framer-motion`** reveal **if** **Task 0** approves and dependency confirmed — **no** new chart-animation libraries; respect **Design Goals** “no animated heavy charts on first load” (~345).
9. **Accessibility:** Dashboard **regions** use **`aria-labelledby`** (or equivalent) pointing at visible **section headings**; chart **`aria-label` / `role="img"`** patterns per **17.5** + **NFR.17.5**. **axe** on **`/ops`** documented in **Progress Notes**.
10. **Copy (NFR.17.8):** New **section titles** and **chart summaries** live in the **single** module chosen in **Reconciliation** (extend **`ops-kpi-card-copy.ts`** and/or add **`ops-dashboard-page-copy.ts`** / **`ops-dashboard-copy.ts`**); re-use **`ops-charts-copy.ts`** for shared empty strings where applicable.
11. **Authz (NFR.17.6):** **No** changes to **`requireOpsStaffPage`**, RLS, or role mapping; new server code is **read** paths only.
12. **Documentation (NFR.17.1):** Extend **[`docs/ops-design-system-parity.md`](../ops-design-system-parity.md)** with **§ 17.6** (or **§ 17** subsection **“Dashboard (`/ops`)”**) — **layout** diagram or grid description, which charts use which props, **a11y** for regions, **MVP** choice reference.
13. **Tests:** Add or update tests for **`OpsDashboardView`** composition (loader **mock** or **integration** pattern consistent with repo — **Task 0** picks **`*.test.tsx`** location); protect **grid structure** and **presence** of chart regions / scorecards per **MVP**.
14. **QA:** **Tablet** spot-check (**FE.5.7** extension per epic ~370); document viewport + notes in **Progress Notes**.
15. **Quality:** **`npm run lint`** and **`npm run test`** green after implementation.
