2. **Table columns** (each row = one grep hit, or a documented **rationale** if multiple hits collapse — default is **one row per line match**):
   - **File path** (repo-relative)
   - **Line number**
   - **Context** — **5 characters before and 5 after** the match (or epic-consistent window if a tool outputs a longer snippet — **must** state the rule in the audit header)
   - **Current text** (the matched token / substring)
   - **Proposed action** — one of the **enums** from the epic: **`rename to driver`** / **`keep — DB scope deferred to Epic 17`** / **`keep — capstone reference`** / **`keep — historical migration`**

3. **Produced via grep tooling** (e.g. **`rg`**, **`grep`**, or IDE search) — the audit file’s **header** records: **command(s)**, **date**, **commit SHA** (or **branch@date** if SHA unavailable), and a **Sign-off** block (name + role or **“Unreviewed — draft”** until PO signs).
