## Story

- As a **customer** with an **old `/q/[token]/pay` link**, I need to be **redirected** to **`/q/[token]/accept`** so I see **EFT bank details and acceptance** instead of a **404** — per **US-N7** / **Q33**.

- As **ops/platform**, I need a **dated runbook reminder** to **delete** the temporary **`pay/route.ts`** **on or after 2026-07-25** so the deprecation window does not linger indefinitely.

- As **engineering**, I need a **single-file** redirect with **no** PayFast or **page** UI under **`pay/`** — consistent with **N2** and **§8**.

## Acceptance Criteria (ACs)

1. **New route module:** **`src/app/(quote)/q/[token]/pay/route.ts`** exports **`GET`** using **`NextRequest`** and **`NextResponse.redirect(..., 302)`** to **`/q/{token}/accept`** on the **same origin** as the incoming request (derive base from **`request.url`** / **`URL`** — per epic ~795–799).
2. **Deprecation comment:** File includes a comment stating **Epic 16 Theme N** and **90-day deprecation — delete after 2026-07-25** (align with epic ~789).
3. **No page tree:** **`src/app/(quote)/q/[token]/pay/page.tsx`** and **any other** **`pay/`** siblings **except** the **`route.ts`** (and unavoidable colocated tests if the project adds them) **do not exist**; if found, **delete** (per **US-N2** / epic ~802).
4. **Runbook:** **[`docs/ops-runbook.md`](../ops-runbook.md)** contains a subsection under **Epic 16 Theme N** (or equivalent clear heading) that records **2026-07-25** as the date to **remove** **`pay/route.ts`** / the redirect and **why** (legacy PayFast URLs).
5. **Typing:** **`params`** / route context matches **Next 15** + repo patterns (see **Reconciliation**); **`npm run lint`** and **`npm run test`** stay green.
6. **Tests (lightweight):** Add or extend tests that assert the **redirect** **location** and **status** for a **GET** to the **`pay`** route (pattern: **request** against handler or **integration** test as the codebase already does for **`route.ts`** files — if no harness exists, document **manual curl** steps in **Progress Notes** and add a **minimal** test stub only if straightforward).
