## Story

- As a **traveller**, I need the trip-request funnel to **look and read** like the rest of Vestroo (marketing + account), so I **trust** the flow.
- As **design / product**, I need **Epic 17/18** typography and surfaces applied consistently across **all four slides**, so the funnel feels **cohesive** on mobile and desktop.

## Acceptance Criteria (ACs)
1. **Slides 1–3 + confirmation (slide 4):** Card / panel **surfaces**, borders, and elevation align with **Epic 17/18** guidance — visually consistent with **marketing** pages and **account** portal (no one-off “mint shell” unless tokenised to match brand).
2. **Typography:** Section / slide titles use **`font-[family-name:var(--font-montserrat)]`** (or equivalent per project convention); **body** copy and form labels use **Poppins** via **`var(--font-poppins)`** / body stack so headings vs body **contrast** the epic intent.
3. **Primary CTA:** **Continue** (or **Next** if copy deferred) and **Submit trip request** use the **brand primary** button treatment (**`vest.rust` / account-accent** semantic — match **Button** usage on marketing + account, not ad-hoc hex unless tokenised).
4. **Progress:** **`TripRequestFunnelProgress`** remains **keyboard-accessible** and **readable on small viewports** (touch targets, label legibility, no clipped step names) — **NFR.19.2**.
5. **Inline errors:** Field-level and submit-level error text uses the agreed **`--account-danger`** resolution path (**Reconciliation** table) with **`aria-live`** / **`role="alert"`** preserved or improved — **NFR.19.2**.
6. **Slide 4 success:** Success region **visually** matches **Epic 18** empty/success patterns (contained card, calm hierarchy, optional soft accent) — **without** implementing full **FE.19.12** copy unless **Task 0** explicitly includes a **minimal** shell only.
7. **Lighthouse (mobile):** Run **mobile** Lighthouse (CLI or DevTools); record scores. **Targets:** performance **≥ 90**, accessibility **≥ 95**, best practices **≥ 95**. **Document** any shortfall and **tradeoff** in **Story Progress Notes**.

## Story Progress Notes

### Task 0 / scope (agent decisions — 2026-05-01)

- **19.11 vs 19.12:** Visual/styling only on slide 4 success; **no** FE.19.12 copy or structured “what happens next”. CTA labels remain **Next** / **Submit trip request** (optional rename to “Continue” deferred).
- **`--account-danger`:** Did **not** wrap the funnel in **`data-account-theme="light"`** (avoids affecting marketing embed / duplicate theme semantics). Inline and submit errors use Tailwind **`text-destructive`** / **`border-destructive`**, which resolve to **`hsl(var(--destructive))`** on **`:root`** — same HSL components as **`--account-danger`** in light per **`globals.css`**. **`aria-live` / `role="alert"`** preserved on submit errors and field alerts.
- **FE.19.10:** No removal or reorder of analytics **`useEffect`** / handlers in **`TripRequestBookingShell.tsx`** (`trackBookingFunnelView`, `trackBookingFunnelSlideView`, `trackBookingFunnelSlideComplete`, `trackBookingFunnelSubmitSuccess`, `trackBookingFunnelSubmitError`, perf anchor ref).

### Implementation summary

- **Shell & page:** Card chrome uses **`border-border`**, **`bg-card`**, **`text-card-foreground`**, **`shadow-sm`**; slide **`h2`** uses **`font-display`** (Montserrat stack from **`tailwind.config.ts`**); body uses **`font-Poppins`** on form and key copy. Slide 4 success wrapped in **`rounded-xl border border-border bg-muted/30 p-5 sm:p-6 shadow-sm`** (Epic 18–style contained hierarchy; no new copy).
- **Primary CTA:** **`src/components/ui/button.tsx`** default variant updated from hardcoded teal to **`bg-vest-rust` / `hover:bg-vest-rust-dark`** so **Next** / **Submit** match marketing **`BookingSearchForm`** / token doc (**§1.1**).
- **Progress:** Completed steps **`bg-primary`** + label **`text-primary`**; current step circle **`bg-vest-rust`** + ring; upcoming **`bg-muted`**; step circles **`min-h-9 min-w-9`** with existing **`flex-wrap`** / **`min-w-[4.25rem]`** for 320px.
- **Slides:** Replaced **`#25A89B`** / **`text-red-*`** with **`ring-ring`**, **`primary`**, **`vest-rust`**, **`text-destructive`**, and shadcn semantic surfaces. **`AddressAutocomplete`** (trip inputs) uses **`border-destructive`** + **`focus:border-primary`** / **`focus:ring-primary`**. **`Label`** required asterisk uses **`text-destructive`** globally.
- **`globals.css`:** No booking-scoped alias added (not required).

### Lighthouse (mobile CLI)

- **Command:** `npx lighthouse@11.7.1 http://localhost:3001/book/trip-request --form-factor=mobile --only-categories=performance,accessibility,best-practices --chrome-flags="--headless --disable-gpu --no-sandbox --disable-dev-shm-usage" --max-wait-for-fcp=120000` (dev server on **3001** because **3000** was in use).
- **Scores:** Performance **45**, Accessibility **95**, Best practices **96**.
- **Tradeoffs:** Performance target **≥ 90** **not met** on **unthrottled `next dev`** (expected: dev bundles, HMR, **`framer-motion`**, Google Places / fonts). **Mitigations for a future perf pass:** production **`next build` + `next start`** or Vercel preview run; code-split Places; audit **`reduceMotion`** boundaries. **A11y** and **best-practices** meet **≥ 95** goals.
