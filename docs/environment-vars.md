# Environment variables (server reference)

Server-only variables that affect booking checkout and ops flows. For local setup, copy **`.env.example`** to **`.env.local`**. **Epic 14 (Theme B + US-D3)** signposts below stay aligned with **`.env.example`**, **[`docs/stories/14.2.story.md`](stories/14.2.story.md)**, and **[`docs/stories/14.7.story.md`](stories/14.7.story.md)** (single **purpose** / **default** / **parser** per variable; no second contradictory row in other sections).

| Variable | Default | Purpose, rollback, rotation |
| -------- | ------- | --------------------------- |
| `QUOTE_LINK_SIGNING_KEY` | *None* in production — must be set where **`/q/*`** quote links are issued or verified. Under **`next dev`**, if unset or **shorter than 32 UTF-8 bytes** after trim, a fixed dev-only HMAC key is used (see **`quote-tokens.ts`**); **`signQuoteToken`** also **lazy-initialises** if instrumentation did not run. Set a real secret in **`.env.local`** for parity. | **Epic 14 / 14.2 (Q16):** **Server-only** HMAC secret for **opaque** tokens in **`/q/[token]/accept`**, **`/q/[token]/pay`**, **`/q/[token]/reject`** (walk-in **quote** email links). **Never** prefix with `NEXT_PUBLIC_*`, never log, never echo in client-facing errors. **Length:** UTF-8 string **≥ 32 bytes** after trim (enforced in signing paths; weak/missing key is a startup/configuration failure, not a silent runtime default). **Rollback / dual-key:** *Not* implemented — rotation is **deploy a new key**; tokens signed with the old key then fail verification until you **re-send the quote** or the customer is issued a **new** quote (new HMAC, new `expires_at` window). **Rotation after suspected leak:** generate a new 32+ byte value, set in the runtime env, deploy, and treat old in-flight links as invalid. **`.env.example`:** commented template under “Quote deep-link HMAC (Epic 14 / Theme B)”. |
| `QUOTE_FIRST_FOR_NON_TRIVIAL_INTENTS` | **ON** when **unset** or **empty** (per **`.env.example`**: after **14.7**, “flag missing” = feature **on**). | **14.7 (US-D3 / Q13):** **Non-trivial** intents use **quote-first** (`submitted` at create, no immediate checkout redirect) **vs** legacy **`pending`** + redirect. **In scope when ON:** `hourly_hire` and `experience_package` on the main book flow, and `trip_request` from the trip-request funnel. **`point_to_point`** is **unchanged** (direct to checkout per **Q13**; not toggled as “non-trivial”). **OFF (rollback):** set to `0`, `false`, `no`, or `off` (case-insensitive, after trim). **Any other value** (e.g. `1`, `true`, `yes`, `on`, or arbitrary text) = **ON**. **Parser (authoritative):** `isQuoteFirstForNonTrivialIntentsEnabled` in `src/lib/quote-first-non-trivial-intents.ts`. **`.env.example`:** **Story 14.7** block; optional commented **`# QUOTE_FIRST_FOR_NON_TRIVIAL_INTENTS=1`**. **Epic 16 / Theme N — note:** the legacy “direct redirect” path described above is **retired** (Q31 removes the checkout provider integration); EFT settlement is recorded by ops via **`markBookingPaymentReceived`** (US-N3). The flag continues to gate **quote-first vs `pending`** booking creation only. |

## Payments

Epic 16 / **Theme N (US-N2 / Q31)** — the checkout provider integration was **physically
removed**. There are **no active payment-provider env vars** documented here. Settlement is
recorded out of band via EFT (US-N3 ships **`markBookingPaymentReceived`**); patterned-checkout
provider work is **deferred** per **[`docs/epic-9.md`](./epic-9.md)** § SH.9.5.
